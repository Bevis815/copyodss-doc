# CopyOdds दस्तावेज़

CopyOdds, [Polymarket](https://polymarket.com) पर बना एक **स्मार्ट मनी एनालिटिक्स + ऑटोमेटेड कॉपी ट्रेडिंग** प्लेटफ़ॉर्म है: मज़बूत ट्रैक रिकॉर्ड वाले प्रेडिक्शन-मार्केट ट्रेडर्स खोजें, और एक कस्टोडियल ट्रेडिंग अकाउंट में उनके फ़िल्स को अपने-आप कॉपी करें।

ये दस्तावेज़ मौजूदा App (`app.copyodds.io`) के इंटरफ़ेस और फ़्लो को दर्शाते हैं। बटन और मेन्यू के नाम App के अंग्रेज़ी UI से मेल खाते हैं।

## चार चरणों में शुरुआत करें

1. **लॉग इन / साइन अप** — ईमेल कोड, Passkey, या Telegram
2. **डिपॉज़िट** — Polygon या BSC पर USDC / USDT अपने कस्टोडियल एड्रेस पर भेजें
3. **प्लेटफ़ॉर्म Gas खरीदें** — ऑटोमेटेड कॉपी ट्रेडिंग के लिए सर्विस-फ़ीस क्रेडिट (यह ऑन-चेन MATIC नहीं है)
4. **कॉपी करें** — **Leaderboard** या **Smart money** में एक ट्रेडर चुनें → **Follow** (फ़ॉलो करें) पर टैप करें → एक कॉपी मोड चुनें (डिफ़ॉल्ट: **Ratio**) → नियम सेव करें

समझ नहीं आ रहा कहाँ से शुरू करें? [App टूर](getting-started/app-tour.md) से शुरुआत करें।

## कॉपी करना शुरू करने से पहले

| आइटम | आवश्यकता |
|------|-------------|
| प्लेटफ़ॉर्म Gas | **0 से अधिक** (वरना आप कॉपी करना चालू नहीं कर सकते; Gas ख़त्म होते ही buys स्किप हो जाती हैं) |
| USDC बैलेंस | असली buys के लिए कम से कम लगभग **$1** की सलाह दी जाती है |
| ट्रेडिंग अकाउंट | आमतौर पर लॉगिन के बाद अपने-आप खुल जाता है |

## पढ़ने का सुझाया गया क्रम

1. **शुरुआत करें** (यह क्या है → क्विक स्टार्ट → App टूर)
2. **लीडरबोर्ड / स्मार्ट मनी** (ट्रेडर्स चुनें; स्कोर और ड्रॉडाउन देखें)
3. **कॉपी ट्रेडिंग** (कॉपी कैसे शुरू करें, मैनेज करें और जाँचें)
4. **वॉलेट** (डिपॉज़िट, Gas, विड्रॉ, ट्रांज़ैक्शन हिस्ट्री)
5. **अकाउंट और सेटिंग्स, सुरक्षा** (अपना अकाउंट सुरक्षित रखें)
6. **एफ़िलिएट** (जब आप शेयर करके कमाना चाहें)

## इन दस्तावेज़ों के बारे में

- ये दस्तावेज़ केवल प्रोडक्ट के उपयोग का तरीका बताते हैं और **निवेश सलाह नहीं हैं**।
- इंटरफ़ेस लगातार अपडेट होता रहता है। अगर स्क्रीनशॉट आपके वर्ज़न से थोड़े अलग दिखें, तो App में जो दिख रहा है उसी को मानें।

## सपोर्ट से संपर्क करें

कृपया ये तैयार रखें: आपका रजिस्टर्ड ईमेल, कार्रवाई का समय, एरर के स्क्रीनशॉट, और **Trade history** से संबंधित ID / स्टेटस / ऑन-चेन हैश।
