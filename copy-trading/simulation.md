# 模拟跟单（Simulation copy trading）

**模拟跟单**用一个「虚拟钱包」来跑你的跟单策略——**不动真钱**，纯粹用来试参数、看效果。适合刚上手、还不想真投钱的新手。

入口：**Simulation copy trading** → `/copy-trading/simulation`

> 模拟跟单是逐步开放的功能，如果你的界面里看不到这个菜单，说明暂未开放。

***

## 它和真跟单的区别

| | 模拟跟单 | 正式跟单 |
|--|---------|---------|
| 用钱 | 虚拟余额 | 你的托管 USDC |
| Gas | 不需要 | 需要（每笔约 0.5% 服务费） |
| 会不会亏 | 不会真的亏 | 会 |
| 作用 | 试参数、看长期表现 | 真实收益 |

***

## 上手三步

### 1. 创建虚拟账户

点 **创建虚拟账户（Create virtual account）**，填写：

| 字段 | 说明 |
|------|------|
| 账户名称 | 方便自己区分，比如「测试-A」 |
| 初始余额 | 模拟本金 |
| 有效天数 | 到期后不再开新仓，已有仓位仍可平掉或结算 |

### 2. 添加要跟的地址

在「Copy addresses」里添加交易员地址，可以给这条策略起个名字、写点备注。

### 3. 设置策略

| 设置 | 说明 |
|------|------|
| 复制方式 | 按比例 / 固定金额 |
| 方向 | 买和卖 / 只买 / 只卖 |
| 单笔最小 / 最大金额 | 每一笔的金额区间 |
| 单市场上限 | 同一个市场最多投多少 |
| 每日上限 | 一天最多投多少 |
| 最大滑点 | 太大就不成交 |
| 执行延迟 | 模拟「反应慢一点」的情况 |
| 市场冷却 | 同一市场两次跟单之间最少间隔 |
| 连续失败暂停 | 连续失败几次后先停一停（默认 10 次） |

点 **开始模拟跟单（Start simulation copy）** 即可运行。

***

## 看结果：五个标签页

| 标签 | 内容 |
|------|------|
| **Copy addresses** | 你添加的地址、策略设置、状态 |
| **Positions** | 模拟持仓，可手动模拟平仓 |
| **Executions** | 每次模拟成交的份额、费用、状态 |
| **Performance** | 权益曲线、总盈亏、胜率、最大回撤、滑点成本、费用成本等 |
| **Ledger** | 每一笔资金的进出明细 |

### 状态说明

| 账户状态 | 含义 |
|----------|------|
| Active / 运行中 | 正常 |
| Paused / 已暂停 | 你暂停了，可恢复 |
| Expired / 已到期 | 不再开新仓，已有权益仍可处理 |
| Archived / 已归档 | 收起来；有持仓时不能归档 |

### 平仓时的小提示

手动平仓需要**15 分钟内的市场价格**才有报价；价格过期或缺失时会提示刷新报价。确认前会先给你看预计成交价、滑点、费用、预计回款与预计盈亏。

***

## 一句话总结

模拟跟单最重要的价值是：**让你在真花钱之前，先看清「频繁跟单 + 高滑点 + 小本金」会是什么结果。**
