# How Copy Trading Works

跟单开启后，CopyOdds 会在你关注的交易员成交时，按规则在你的交易账户里**尝试**下单。

**是否跟单成功，请以「交易记录（Trade history）」为准**；「动态（Copy activity）」只展示交易员公开动作。

![交易记录](../.gitbook/assets/change_doc.png)

***

## 执行流程

1. 检测到 leader 在 Polymarket 的公开成交（买 / 卖）
2. 查找你对该地址的跟单规则，并检查方向是否匹配
3. 按**固定金额**或**你的可用 USDC 比例**计算目标名义金额
4. 在滑点容忍范围内尝试下单
5. 成交则扣减对应 **平台 Gas**（约名义金额的 0.5%），并更新持仓 / 记录

***

## 跟单成功 vs 跳过 vs 失败

| 结果 | 含义 |
|------|------|
| **Filled / 已成交** | 跟单订单成交 |
| **Skipped / 已跳过** | 因设置或资金等原因未下单（常见） |
| **Failed / 失败** | 下单被拒或出错 |
| **Settled 等** | 按界面筛选理解结算 / 完成态 |

### 常见跳过原因

- 方向不符（只买 / 只卖）
- 金额低于约 **$1** 最低买入额
- 达到「最多跟买笔数」（默认 1 = 不加仓）
- 滑点过大
- **Gas 不足**或 **USDC 不足**
- 交易员卖出但你没有对应持仓
- 市场暂时无对手盘

***

## 资金不足时规则会怎样？

| 情况 | 规则状态 | 买入 | 卖出（有持仓时） |
|------|----------|------|------------------|
| Gas = 0 | 通常仍「运行中」，可能出现资金提醒 | 跳过 | 仍可能跟 |
| USDC 不够买 | 同上 | 跳过 | 仍可能跟 |
| 手动暂停 | Manually paused | 不跟 | 不跟 |

补足 Gas / USDC 后，到 **My copies** 点 **Resume buys（恢复买单）**（若整条被手动暂停，则点恢复跟单）。

***

## 动态 vs 交易记录 vs 持仓

| 页面 | 内容 |
|------|------|
| Copy activity | 交易员公开买卖 |
| Trade history | 你的跟单尝试与结果 |
| Positions | 你的当前持仓；可 Close / 赎回已结算份额 |
| Daily P&L | 按交易日统计的已实现盈亏曲线 |

今日已实现盈亏通常按账户时区每日固定时刻（如早上 8:00）重新统计，具体以界面说明为准。
