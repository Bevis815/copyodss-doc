# 我的持仓与交易记录

跟单之后，你所有的仓位和每一笔下单结果都在这两个页面看。**新手只要认准这两个页面就够了。**

| 页面 | 入口 | 回答什么问题 |
|------|------|--------------|
| **我的持仓** | My positions → `/executions/positions` | 我现在持有什么，亏了还是赚了 |
| **交易记录** | Executions → `/executions/records` | 系统每一笔跟单的尝试结果 |
| **盈亏** | 交易记录 → Profit/Loss → `/executions/daily-pnl` | 这段时间总共赚了多少 |

***

## 我的持仓

### 你会看到什么

| 字段 | 含义 |
|------|------|
| **市场 / 结果** | 你买的是哪个事件、哪个结果（Yes / No） |
| **均价 / 现价** | 你的买入成本，和当前市场价 |
| **成本 / 市值 / 盈亏** | 花了多少、现在值多少、赚没赚 |
| **Copy sources** | 这笔仓位是哪几条跟单规则累积出来的 |
| **状态** | 持有中 / 待结算 / 已结算 / 已归档 |

### 能做的操作

| 操作 | 说明 |
|------|------|
| **加仓（Buy more）** | 自己再买一点，填 USD 金额 |
| **卖出平仓（Close）** | 市价卖出，锁定盈亏；价格会随市场波动 |
| **批量平仓** | 一次最多平掉若干个持仓 |
| **Redeem（赎回）** | 市场已结束且你赢了，把仓位换成 USDC |
| **查看详情** | 看买入时间、结算方式、完整时间线 |

### 几种状态的含义

| 状态 | 说明 |
|------|------|
| **持有中** | 市场还没结束，可以卖 |
| **待结算** | 暂时不能卖；赢了会出现 Redeem，亏了会自动平掉 |
| **已结算** | 已经变成 USDC 回到余额 |
| **已归档** | 极小或无流动性的仓位，暂时卖不掉；不影响其他操作 |

***

## 交易记录（跟单历史）

每一行代表系统替你做过的一次尝试：

| 状态 | 含义 |
|------|------|
| **Filled / 已成交** | 跟上了 |
| **In progress / 进行中** | 还在处理 |
| **Skipped / 跳过** | 没下单（原因见「失败原因」） |
| **Failed / 失败** | 下单被拒或出错 |

支持按 **Filled / Settled / 未成功** 筛选，点开任意一条可以看到：跟单规则、订单号、买入价与份额、平仓方式（卖出平仓 / 赎回 / 过期）、成本、回款、盈亏、完整时间线与链上哈希。

***

## 盈亏页面（Profit/Loss）

- 上方是**累计盈亏曲线**，可切换 1 天 / 1 周 / 1 月等区间
- 下方是**分期明细**，含今日、昨日与每天的账户盈亏变化
- 曲线统计口径与 Polymarket 账户盈亏保持一致；如果官方数据暂时取不到，页面会提示改用平台账本数据

> 业务日的起点时间以页面显示为准（例如某天 08:00 起算），跨天看数据时留意这个说明。

## 新手常见疑问

**为什么持仓显示的盈亏和余额对不上？**  
持仓盈亏是「按当前市价估算」，未实现部分会随价格变动；余额里的数字只在你卖出或赎回后才真正落袋。

**为什么卖出失败？**  
常见原因：市场当时没有买单、份额被挂单占用、剩余仓位低于最小卖出数量。稍后再试即可。

**为什么赢了却没看到钱？**  
市场结算后需要一点时间入账，可点 **Redeem** 手动赎回；显示「待结算」时暂时不能操作。
