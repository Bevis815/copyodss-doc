# 跟单设置说明

跟单向导里可配置的参数说明。未在向导中出现的字段（如部分每日限额、延迟等）以当前 App 实际界面为准；旧版文档中的高级限额可能已收敛。

***

## 基础设置

| 设置 | 说明 |
|------|------|
| **Leader address** | 要跟的钱包地址，必须正确 |
| **Name** | 规则显示名，可选 |
| **Copy mode** | 三选一：**比例**（默认）/ **按余额比例** / **固定金额** |
| **跟单比例** | 比例模式专用：对方成交 × 比例 = 你的下单金额 |
| **Slippage tolerance** | 相对交易员成交价可接受的偏离；默认 **15%**，可调 1%–100% |

### 滑点怎么理解？

滑点设得**太紧**：更容易因价格变动跳过或失败。  
滑点设得**太松**：更容易成交，但成交价可能更差。  
默认 15% 是为了提高成交概率；请按自己的风险偏好调整。比例模式另有「对方下单资金区间」和「跟单比例」两个参数，详见 [三种跟单模式](copy-modes.md)。

***

## 比例模式专属参数

| 设置 | 说明 |
|------|------|
| **跟单比例（Copy ratio）** | 0.1%–100%；页面会给出「约 N 笔/天」的推荐值 |
| **对方下单资金区间** | 按对方历史最大成交换算；低于下限跳过，高于上限按「上限 × 比例」计算 |

完整解释与举例见 [三种跟单模式](copy-modes.md)。

***

## 高级设置

| 设置 | 说明 |
|------|------|
| **Direction · Both sides** | 买和卖都跟 |
| **Direction · Buy only** | 只跟买 |
| **Direction · Sell only** | 只跟卖 |
| **Max open copy buys** | 同一规则下最多同时「跟买」相关笔数；**默认 1 = 不加仓**；滑到最大显示 **All = 不限制** |

### 为什么默认不加仓？

预测市场单笔仓位叠加很快。默认 1 有助于控制单市场风险；确认策略合适后再提高。

***

## 平台侧默认行为（了解即可）

- **Copy delay**：当前产品侧常见为立即尝试（无额外人为延迟）
- **连续失败暂停**：平台可能在多次失败后短暂暂停买单（具体阈值以线上为准）；修复问题后可在「我的跟单」恢复

***

## 与资金相关的「软限制」

这些不一定是设置项，但效果类似限制：

| 情况 | 效果 |
|------|------|
| Gas = 0 | 买单跳过；需购买 Gas 并「恢复买单」 |
| USDC 不足 | 买单跳过；可充值或降低金额 / 比例 |
| 低于约 $1 | 买单可能无法满足交易所最小名义金额 |

***

## 修改设置

1. 打开 **My copies**
2. 找到规则 → **Edit**
3. 保存后只影响后续成交

模拟跟单（Simulation）若在你的环境开启，可能暴露更多限额类参数；默认正式跟单以向导字段为准。

***

## 「一键跟单」页面（Quick copy）上的字段

除了从交易员详情发起跟单，你也可以在 **一键跟单** 页面（`/copier`）直接粘贴地址来设置：

| 字段 | 说明 |
|------|------|
| **跟单比例** | 按可用余额的百分比跟随；100% 用满余额，5% 属于轻仓 |
| **单笔上限（USDC）** | 每一笔最多投入多少 |
| **总上限（USDC）** | 所有跟单合计最多投入多少 |
| **自动跟单开关** | 打开后系统会用托管钱包自动复制该用户的订单 |

同一地址重复设置会**覆盖**之前的规则，建议改完到「我的跟单」确认一次。
