# Understanding Trader Metrics

榜单与详情页上的数字口径不完全相同。下面按「你在界面上最常看到的字段」说明。**所有指标仅供参考，不保证未来表现。**

***

## 综合评分与档位

| 概念 | 说明 |
|------|------|
| **综合分 / 交易员评分** | 多因子模型综合结果，越高通常代表综合表现更好 |
| **榜单排名** | 默认综合排名可能含多维 rank，**不等于**单纯按综合分从高到低 |
| **档位（S–D）** | 对地址质量的分档标签（如 S 顶尖聪明钱 → D 谨慎 / 高风险） |
| **风险** | Low / Medium / High 等风险等级提示 |

### 评分因子（常见）

| 因子 | 含义（简化） |
|------|----------------|
| 预测能力（Edge） | 预测 / 定价优势相关 |
| 盈利能力 | 赚钱能力相关 |
| 仿跟单（Copyability） | 在延迟与滑点假设下是否容易被跟住 |
| 回撤健康 | 回撤是否可控 |
| 存续一致性 | 表现是否持续、稳定 |
| 风格扣分 | 如博彩集中度等特征可能扣分 |

评分窗口多为近窗样本，不是账户诞生以来的全部历史。

***

## 列表 / 卡片常见指标

| 指标 | 怎么理解 |
|------|----------|
| **总盈亏 / P&L** | 统计口径下的盈亏金额；注意是否为近窗或官方 PnL 服务口径 |
| **近 7 日盈亏** | 短期表现；波动大时参考价值有限 |
| **胜率** | 已平仓样本中猜对比例；高胜率 ≠ 一定赚钱 |
| **回撤 / DD** | 相对峰值的回撤，通常越低越好 |
| **跟单适配（Copy fit）** | 仿真可跟性；高/中/低 |
| **盈亏比（Profit factor）** | 盈利合计相对亏损合计的比率类指标 |
| **稳定性 / 活跃度** | 收益波动与交易频率相关 |
| **近 7 日笔数 / 成交量** | 是否还在活跃交易 |
| **平均已平仓收益** | 已平仓样本的平均回报类指标 |

带「仿真」标记的列（回测盈亏、跟单损失、滑点等）是**假设延迟成交**下的模拟，**不是**平台用户真实跟单结果。

## 详情页快照（常见字段）

| 字段 | 说明 |
|------|------|
| 当前资金 | 交易员侧资金规模参考 |
| 总盈亏 / 未实现盈亏 | 已实现与持仓浮动 |
| 总成交量 | 交易活跃度参考 |
| 总回报率 / 平均利润率 | 回报类比率 |
| 胜 / 负次数 | 样本结构 |
| 盈亏比 | 盈利质量 |
| 最大单笔 / 最大亏损（回撤） | 尾部风险 |
| 近期活跃 | 是否仍在交易 |

***

## 「真实跟单成绩」vs「跟单仿真」

| 类型 | 含义 |
|------|------|
| **跟单仿真** | 系统用延迟 + 滑点假设回测「如果跟单会怎样」 |
| **真实跟单成绩** | 平台上实际跟该地址的用户样本（ROI、跟单盈亏、订阅人数等）；样本不足时可能不展示 |

两者都**不能**保证你跟单后的结果。

***

## 阅读建议

1. 先看评分、回撤、可跟性，再看总盈亏
2. 样本太少时，胜率和 ROI 容易失真
3. 做市型 / 极端集中押注型地址，指标好看也不等于适合跟
4. 最终以你自己的 **交易记录** 评估跟单效果
