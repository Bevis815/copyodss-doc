# 如何选择交易员

没有「必赚」交易员。选人时建议把**可跟性、风险、活跃度、资金规模**放在「历史赚了多少」前面。

***

## 推荐选人流程

### 1. 先定自己的约束

- 单笔跟单金额（或余额比例）上限
- 能接受的最大回撤与连续亏损
- 偏好的市场类型（政治 / 体育 / 加密等）

### 2. 用筛选缩小池子

- 新手可从 **主推跟单**、**可复制性高**、**稳健型**、**低回撤** 入手
- 避开明显不适合跟单的风格（如强做市 / 极端博彩特征），除非你非常清楚风险
- 样本过少（交易次数很少）的地址，胜率和收益参考价值有限

### 3. 打开详情交叉验证

在详情页重点看：

| 看什么 | 为什么 |
|--------|--------|
| 交易员评分 + 因子 | 综合是否适合跟 |
| 回撤 / 风险提示 | 会不会「赚得猛、回撤也猛」 |
| 近 7 日活跃与盈亏 | 人还在不在交易 |
| 跟单仿真 | 延迟下是否容易跟住（仿真 ≠ 真实） |
| 真实跟单成绩 | 有足够样本时更有参考；样本不足时勿过度解读 |

### 4. 小金额试跟

1. 用较小固定金额或低比例创建规则
2. 观察 1–3 天「交易记录」里的成交 / 跳过 / 失败原因
3. 再决定是否加大金额或换人

***

## 常见误区

| 误区 | 更稳妥的做法 |
|------|----------------|
| 只看总盈亏最高 | 同时看回撤、样本、可跟性 |
| 把仿真 ROI 当自己会赚的钱 | 仿真有延迟/滑点假设；以你的交易记录为准 |
| 胜率接近 100% 就跟 | 看样本数、未平仓与回撤是否匹配 |
| 跟做市型「刷量」地址 | 普通跟单很难复制其成交结构 |
| 一次跟很多人、金额很大 | 先少而精，确认 Gas / 资金 / 规则都正常 |

***

## 什么时候该换人或减仓

- 近期活跃度明显下降
- 回撤或风险提示恶化
- 你的交易记录里大量滑点失败 / 长期跳过
- 风格与你的资金规模不匹配（单笔过大或过碎）

选好人之后，具体操作见 [如何跟单交易员](../copy-trading/how-to-follow.md)。
