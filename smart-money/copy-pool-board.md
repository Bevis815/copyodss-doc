# 排行榜（跟单池每日盈利）

**排行榜**是 App 的首页（`/`），展示平台跟单池里账户的**当日盈利**排名，相当于一份「最近谁跟得好的成绩单」。

界面上会写明**榜单日期（业务日）**，业务日的起点时间以页面显示为准。

***

## 页面上的内容

| 元素 | 含义 |
|------|------|
| **Board · 日期** | 这份榜单统计到哪一天 |
| **Daily PnL（当日盈利）** | 该账户这一业务日赚了多少 |
| **7D（近 7 日）** | 最近 7 天的盈亏 |
| **本期领跑 / 排名** | 榜单上的名次 |
| **查看分析 / 查看账户** | 跳到该账户的详情 |
| **Top N / 全部 N 位** | 只看前几名，或展开完整榜单 |

***

## 怎么用

1. 打开 App，默认就在排行榜
2. 先看**当日盈利 + 近 7 日**，只有一天赚钱不代表稳定
3. 点 **查看分析** 或 **查看账户**，看看这个账户跟的是谁
4. 确认没问题后，直接在榜单上点 **Follow（跟单）**，会弹出跟单设置窗口

> 榜单里的账户本身也是跟单者——他们赚钱说明「跟这类交易员有时有效」，不代表你跟了同样会赚。

***

## 注意事项

- 榜单每天更新，昨天的名次不代表今天
- 单日盈利很容易被某一笔大押注影响，**别只看第一名**
- 想按更细的条件挑人，去 [聪明钱](leaderboard.md) 用筛选器
- 榜单地址也可以直接分享：`https://app.copyodds.io/@0x地址`
