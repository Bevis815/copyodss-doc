# 聪明钱排行榜

「聪明钱」排行榜帮助你发现适合跟单的 Polymarket 交易员。入口：**Smart money** → `/smart-money`（App 首页默认跳到这里）。

![聪明钱排行榜](../.gitbook/assets/smarket_doc.png)

***

## 页面能做什么

1. **浏览榜单** — 卡片 / 表格查看盈亏、评分、胜率、近 7 日等
2. **搜索地址** — 按钱包地址查找
3. **筛选** — 分类、快速预设、高级筛选（档位、风格、指标区间、可跟性等）
4. **排序周期** — 综合榜 / 周榜 / 月榜（默认多为综合排名，不等于单纯按综合分降序）
5. **跟单** — 点 **Follow** 进入跟单设置；或进入详情再决定

***

## 榜单数据口径（必读）

- 盈亏曲线、近 7 日 / 总盈利等常来自 Polymarket 官方 PnL 相关数据
- 胜率、盈亏比等多按**已平仓市场**统计
- 评分与回测相关指标基于**近窗成交**（约 30 天 / 最多约 4000 笔），**不是终身账本**
- **展示榜**通常仅含综合分达到门槛的地址（如 ≥ 40）；连续低分可能出榜
- 「跟单适配 / 回测盈亏 / 滑点」等多为**延迟 + 滑点假设下的仿真**，不是平台真实跟单用户盈亏

> 榜单**不构成投资建议**，过去表现不代表未来收益。

***

## 常用筛选

### 分类示例

全部、政治、体育、电竞、加密、文化、天气、经济、科技、金融、提及等。

### 快速筛选示例

| 预设 | 大致用途 |
|------|----------|
| 主推跟单 | 平台主推、更偏可跟 |
| 稳健型 | 相对稳健风格 |
| 可复制性高 | 仿真下更容易跟住 |
| 近期活跃 | 近窗交易更频繁 |
| 全部可跟 | 可跟单地址 |
| 高胜率 / 高收益 / 低回撤 | 按对应指标收窄 |
| 长期稳定 | 稳定性更好的候选 |

### 高级筛选（常见项）

- 仅显示可跟单地址 / 仅主推（不含做市型）
- 档位（S–D）、交易风格
- 指标范围（如近 7 日笔数、胜率等）
- 排除特定风险标签
- 可跟性：高 / 中 / 低

***

## 交易风格标签（参考）

| 标签 | 含义（简化） |
|------|----------------|
| 信息优势 | 偏提前布局 / 信息型 |
| 套利 | 价差 / 套利特征 |
| 博彩型 | 高波动博彩特征，跟单需更谨慎 |
| 做市型 | 高频做市，通常不适合普通跟单 |
| 综合型 | 一般综合风格 |

***

## 操作建议

1. 先用「主推 / 可复制性高 / 稳健」等预设缩小范围
2. 打开详情看评分因子、回撤与风险提示
3. 小金额 Follow 测试，再逐步调整
4. 分享交易员时使用详情链接格式：`https://app.copyodds.io/@0x地址`（中文界面可带 `/zh`）
