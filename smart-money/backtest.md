# 跟单回测（Copy backtest）

**回测**就是「如果我当初跟了这个交易员，会怎样」。你可以自己设定投入金额、跟单方式和滑点，让系统把这个交易员近期的成交**重演一遍**，看看结果大概是什么样。

入口：交易员详情页 → **Backtest（回测）** → `/smart-money/backtest`

***

## 回测前要设置什么

| 设置项 | 说明 | 常见取值 |
|--------|------|----------|
| **跟单方式** | 每次固定金额，还是按可用余额的比例 | 固定金额 / 比例 |
| **单笔金额** | 固定金额模式下，每笔投多少 | 最低约 $1 |
| **投入总额** | 你打算给这次回测多少本金 | 最低 $30 |
| **滑点容忍** | 允许的成交价偏离，1%–30% | 越大越容易成交，但成本更高 |
| **回看天数** | 重演最近多少天的成交 | 1–90 天 |
| **风险预设** | 一键套用保守 / 均衡 / 激进 | 可单独再调 |

点 **Run backtest（开始回测）** 后稍等几秒即可出结果。

***

## 结果怎么看

| 指标 | 大白话解释 |
|------|-----------|
| **Buys filled / skipped** | 回测里有多少笔买进了、多少笔被跳过（钱不够、滑点太大等） |
| **Est. PnL / ROI** | 估算的盈亏金额、相对本金的回报率 |
| **Win rate** | 平掉的仓位里赚钱的比例 |
| **Max drawdown（最大回撤）** | 中途最亏的时候，账户从最高点掉下来多少 |
| **Round trips** | 完整「买进→卖出」的次数，次数太少说明样本不足 |
| **权益曲线** | 账户余额随时间的走势，紫色柱子是回撤 |
| **Markets（目标 vs 模拟）** | 逐个市场对比：交易员买了什么、你的模拟结果如何 |

***

## 回测不等于实盘

- 回测是**模拟**：假设了延迟、滑点、流动性，实际跟单会有差异
- **滑点调大**：买的笔数变多，但 ROI 往往变差
- 有些活跃钱包的交易记录会被截断，页面会提示「数据不完整」
- 结论只能当参考，最终以你自己的 [交易记录](../copy-trading/positions-and-records.md) 为准

***

## 推荐用法

1. 在 [聪明钱](leaderboard.md) 或排行榜里选中一个人
2. 进详情页先看评分和回撤，再打开回测
3. 用**保守**预设跑一次，再跑一次**均衡**做对比
4. 如果回测里「skipped」特别多，说明这个人的单子太频繁或太小，不适合你现在的资金量
