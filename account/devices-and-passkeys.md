# 设备管理与 Passkey

这一页讲两件安全的事：**哪些设备登录过你的账户**，以及**怎么用 Face ID / 指纹快速登录**。

入口：设置 → 安全 → **Devices（设备）** → `/settings/devices`；Passkey 在设置里管理 → `/settings/passkeys`

***

## 一、设备管理（Devices）

### 页面上能看到什么

| 字段 | 含义 |
|------|------|
| 设备名 | 例如你的手机型号、系统名称；无法识别时显示「未知设备」 |
| **当前设备** | 你现在正在用的这台 |
| **最近活跃** | 上次使用时间 |
| 活跃会话 | 这台设备上有几个登录会话 |
| 可提现时间 | 新设备通常需要等待一段时间才能提现 |

### 移除设备

1. 找到不认识的设备 → 点 **Remove（移除）**
2. 确认后，这台设备会被移除，**它上的登录会话立刻失效**

### 什么时候该移除

- 换了手机 / 电脑，旧设备还在列表里
- 登录记录里有你不认识的设备
- 怀疑账号被别人使用

> 移除设备后那台设备需要重新登录（邮箱验证码 / Telegram / Passkey）。

***

## 二、Passkey（通行密钥）

Passkey 是用你手机的 **Face ID、指纹或屏幕锁** 登录，不用输验证码。

### 添加 Passkey

1. 设置 → Passkeys → **Add passkey**
2. 按提示完成 Face ID / 指纹验证
3. 成功后列表里会显示这条 Passkey，以及创建时间、最近使用时间、是否已同步

### 登录时使用

在登录页选择 **Passkey** 登录即可，不用收邮件。

### 删除 Passkey

选中 → **Delete** → 确认。删除后这只设备不能再用 Passkey 登录。

### 常见问题

| 现象 | 怎么办 |
|------|--------|
| 添加时没有弹出 Face ID | 取消后**再点一次「Add Passkey」**，并在弹窗出现后立刻完成验证；先关掉通知横幅 |
| 提示本设备不支持 | 换用系统自带浏览器（iOS 用 Safari、Android 用 Chrome），或直接用邮箱验证码 |
| 提示已存在同名 Passkey | 先删除旧的「Android device」那条；使用代理 / VPN 时先关掉再试 |
| 登录失败 | 改用邮箱验证码登录，Passkey 失败不会影响账户安全 |

> Passkey 只能用于登录，**不能用于提现验证**。
