# Документация CopyOdds

CopyOdds — это платформа **аналитики умных денег + автоматического копи-трейдинга**, построенная на [Polymarket](https://polymarket.com): находите трейдеров рынков предсказаний с сильной историей результатов и автоматически повторяйте их сделки на кастодиальном торговом счёте.

Эта документация описывает текущий интерфейс и сценарии работы приложения (`app.copyodds.io`). Названия кнопок и пунктов меню совпадают с английским интерфейсом приложения.

## Начните за четыре шага

1. **Вход / регистрация** — код по email, Passkey или Telegram
2. **Пополнение** — отправьте USDC / USDT в сети Polygon или BSC на свой кастодиальный адрес
3. **Покупка Platform Gas** — кредиты на оплату сервисных комиссий за автоматический копи-трейдинг (это не ончейн-MATIC)
4. **Копирование** — выберите трейдера в **Leaderboard** или **Smart money** → нажмите **Follow** → выберите режим копирования (по умолчанию: **Ratio**) → сохраните правило

Не знаете, с чего начать? Начните с [обзора приложения](getting-started/app-tour.md).

## Перед началом копирования

| Пункт | Требование |
|------|-------------|
| Platform Gas | **Больше 0** (иначе включить копирование нельзя; когда Gas заканчивается, покупки пропускаются) |
| Баланс USDC | Рекомендуется не менее примерно **$1** для самих покупок |
| Торговый счёт | Обычно открывается автоматически после входа |

## Рекомендуемый порядок чтения

1. **Начало работы** (что это такое → Быстрый старт → Обзор приложения)
2. **Рейтинг / Умные деньги** (выбор трейдеров; проверка оценки и просадки)
3. **Копи-трейдинг** (как начать, управлять и проверять копирование)
4. **Кошелёк** (пополнение, Gas, вывод, история транзакций)
5. **Аккаунт и настройки, Безопасность** (защитите свой аккаунт)
6. **Партнёрская программа** (если хотите зарабатывать, делясь ссылкой)

## Об этой документации

- Эта документация описывает только использование продукта и **не является инвестиционной рекомендацией**.
- Интерфейс постоянно обновляется. Если скриншоты немного отличаются от вашей версии, ориентируйтесь на то, что показывает приложение.

## Связаться с поддержкой

Пожалуйста, подготовьте: email, указанный при регистрации, время действия, скриншоты ошибок, а также соответствующий ID / статус / ончейн-хеш из **Trade history** (история сделок).
