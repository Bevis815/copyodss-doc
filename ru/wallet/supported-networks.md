# Поддерживаемые сети

Для пополнения и вывода поддерживаются **разные сети**. Всегда выбирайте точно так, как указано на странице, чтобы средства не потерялись.

***

## Обзор

| Действие | Поддерживаемые сети | Активы | Тип адреса |
|--------|--------------------|--------|--------------|
| **Пополнение** | **Polygon (PoS)**, **BSC** (если включено) | USDC / USDT | Разный адрес для каждой сети |
| **Вывод** | **Только Polygon (PoS)** | **USDC** | Ваш собственный адрес получателя |

Примеры сетей, не поддерживаемых для пополнения: **основная сеть Ethereum, Arbitrum, Optimism** и т. д. (если продукт явно не добавит их в будущем).

***

## Polygon (PoS)

| Пункт | Описание |
|------|-------------|
| Пополнение | Поддерживается; отображаемый адрес — это адрес вашего кастодиального кошелька (Custodial address) |
| Активы | USDC, USDT |
| Вывод | **Единственная** сеть для вывода; выводите USDC на адрес, который может принимать Polygon USDC |

Большинство пользователей предпочитают Polygon: путь прямее и совпадает с сетью для вывода.

***

## BSC

| Пункт | Описание |
|------|-------------|
| Пополнение | Поддерживается (если включён мост / сеть в продукте) |
| Активы | USDC, USDT |
| Адрес | **Адрес моста**, отличается от адреса в Polygon |
| Вывод | Вывод из CopyOdds в BSC **не поддерживается** |

Выводя средства с биржи через BSC, сначала переключите страницу пополнения на BSC, а затем скопируйте адрес. Зачисление может занять на несколько минут больше.

***

## Распространённые ошибки

| Ошибка | Последствие |
|---------|-------------|
| Вывод через BSC, но скопирован адрес Polygon | Средства могут не зачислиться / их будет трудно вернуть |
| Вывод через Polygon, но скопирован адрес BSC | То же, что выше |
| Отправка USDC в сети Ethereum | Обычно не зачисляется автоматически |
| Указание адреса со страницы пополнения в качестве адреса для вывода | Средства могут вернуться на кастодиальную сторону и вызвать путаницу; выводить нужно на **собственный** внешний адрес |
| Ожидание вывода в BSC | Сейчас вывод поддерживается только в Polygon USDC |

***

## Простые правила

1. **Сначала выберите сеть, затем скопируйте адрес**
2. **Пополнение через Polygon и вывод через Polygon — самый простой вариант**
3. **BSC — только для пополнения; вывести в BSC из этого приложения нельзя**
4. **Используйте только адрес с официальной страницы + функцию Verify deposit address**
