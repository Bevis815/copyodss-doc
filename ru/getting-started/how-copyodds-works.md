# Как работает CopyOdds

От момента «у трейдера исполнилась сделка» до «ваш счёт пытается её скопировать» весь процесс выглядит так:

```text
У трейдера умных денег исполняется сделка на Polymarket
        ↓
CopyOdds обнаруживает публичную сделку
        ↓
Находит ваше правило копирования для этого адреса
        ↓
Рассчитывает размер ордера по правилу (фиксированная сумма или % от вашего баланса)
        ↓
Пытается разместить ордер в пределах проскальзывания (расходует Platform Gas)
        ↓
Результат записывается в историю сделок; активы отображаются в позициях
```

## 1. Поиск трейдеров

- Система постоянно оценивает и отбирает публичные кошельки Polymarket
- Для попадания в **отображаемый рейтинг** обычно требуется, чтобы общая оценка достигала порога (например, ≥ 40); адреса с низкой оценкой могут выбывать из него
- В разделе **Smart money** можно просматривать, искать или анализировать адреса, которых нет в рейтинге (если функция доступна, может действовать дневной лимит)

## 2. Средства и комиссии разделены

| Ресурс на счёте | Назначение |
|---------------------|---------|
| **USDC (и др.)** | Основная сумма для копирования: расходуется при покупке, возвращается при продаже |
| **Platform Gas** | Кредиты на оплату сервисных комиссий: за каждую исполненную копи-сделку списывается около 0.5% от номинальной суммы |

Когда Gas равен 0: вы **не можете создавать / возобновлять правила копирования**. Существующие правила обычно продолжают работать, но **покупки пропускаются**; продажи всё ещё могут копироваться, если у вас есть позиции.

## 3. Как применяются правила копирования

Вы сохраняете одно правило для каждого адреса лидера (повторное сохранение для того же адреса перезаписывает его):

- **Режим копирования** (выберите один; по умолчанию **Ratio**):
  - **Ratio**: каждая сделка лидера × ваш коэффициент = сумма вашего ордера
  - **By balance %**: каждая сделка использует процент от ваших собственных доступных USDC
  - **Fixed amount**: каждая сделка покупает на одну и ту же сумму
  - См. [Три режима копирования](../copy-trading/copy-modes.md)
- **Направление**: Both / Buy only / Sell only
- **Проскальзывание**: сделка не исполняется, если цена ушла слишком далеко (по умолчанию 15%)
- **Коэффициент копирования / диапазон размера** (только в режиме Ratio): определяют, «сколько копировать» и «ордера какого размера копировать»
- **Max open copy buys**: по умолчанию 1 (без добавления к позициям); можно увеличить, максимум — **All (без ограничений)**

Обнаружив сделку лидера, система пытается разместить ордер по этим правилам. Она **не гарантирует**, что каждая сделка будет скопирована.

## 4. Как понять, была ли сделка скопирована

| Где смотреть | Что это показывает |
|---------------|-------------------|
| Copy activity | Что сделал трейдер |
| Trade history | Результаты ваших попыток копирования (исполнено / пропущено / ошибка) |
| Positions | Что у вас сейчас есть |
| My copies | Статус правила: Following / Manually paused / Funding alert |

## 5. Сети для пополнения и вывода различаются (важно)

- **Пополнение**: Polygon (PoS) и BSC (если включено), активы USDC / USDT
- **Вывод**: только **Polygon (PoS) USDC**
- Две сети для пополнения используют **разные адреса** — никогда их не путайте

См. [Поддерживаемые сети](../wallet/supported-networks.md).

## 6. Кратко о модели безопасности

CopyOdds использует **кастодиальный торговый счёт**: один кошелёк на пользователя с изолированными приватными ключами. Для вывода требуется дополнительная проверка через **Authenticator (TOTP)**. См. [Безопасность](../security/wallet-security.md).
