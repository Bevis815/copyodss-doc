# Метрики трейдера

Числа на страницах рейтинга и профиля не всегда рассчитываются одинаково. Ниже приведены поля, которые встречаются чаще всего. **Все метрики носят справочный характер и не гарантируют будущих результатов.**

***

## Общая оценка и уровень

| Понятие | Описание |
|---------|-------------|
| **Overall score / Trader score** | Результат многофакторной модели; чем выше, тем, как правило, лучше общие результаты |
| **Leaderboard rank** | Общий рейтинг по умолчанию может объединять несколько рейтингов и **не** сортируется просто по общей оценке |
| **Tier (S–D)** | Метка уровня качества адреса (например, S = лучшие умные деньги → D = осторожно / высокий риск) |
| **Risk** | Подсказки об уровне риска, например Low / Medium / High |

### Факторы оценки (распространённые)

| Фактор | Значение (упрощённо) |
|--------|----------------------|
| Edge | Преимущество в прогнозировании / ценообразовании |
| Profitability | Способность зарабатывать |
| Copyability | Легко ли за ним успевать с учётом допущений о задержке и проскальзывании |
| Drawdown health | Находятся ли просадки под контролем |
| Consistency | Устойчивы и стабильны ли результаты |
| Style penalty | Такие черты, как концентрация азартных ставок, могут снижать оценку |

Окно оценки — в основном недавняя выборка, а не вся история аккаунта с момента создания.

***

## Распространённые метрики в списках / карточках

| Метрика | Как её читать |
|--------|----------------|
| **Total P&L** | P&L по указанной методике; обратите внимание, взят ли он за недавний период или из официального сервиса PnL |
| **7-day P&L** | Краткосрочные результаты; при высокой волатильности менее показательны |
| **Win rate** | Доля верно предсказанных закрытых сделок в выборке; высокая доля прибыльных сделок ≠ гарантированная прибыль |
| **Drawdown / DD** | Снижение от пикового значения; чем ниже, тем, как правило, лучше |
| **Copy fit** | Симулированная пригодность к копированию: High / Medium / Low |
| **Profit factor** | Метрика-соотношение общей прибыли и общих убытков |
| **Stability / Activity** | Связаны с волатильностью доходности и частотой торговли |
| **7-day trades / Volume** | Продолжает ли он активно торговать |
| **Avg. closed return** | Средняя метрика доходности по закрытым сделкам в выборке |

Столбцы с пометкой «simulated» (backtest P&L, copy loss, slippage и т. д.) — это симуляции, **предполагающие задержку исполнения**, а **не** реальные результаты копирования пользователей платформы.

***

## Сводка профиля (распространённые поля)

| Поле | Описание |
|-------|-------------|
| Текущие средства | Ориентир по размеру капитала трейдера |
| Общий P&L / нереализованный P&L | Реализованный P&L и плавающий P&L по открытым позициям |
| Общий объём | Ориентир по торговой активности |
| Общая доходность / средняя маржа прибыли | Показатели доходности |
| Выигрыши / проигрыши | Структура выборки |
| Профит-фактор | Качество прибыли |
| Крупнейший выигрыш / крупнейший убыток (просадка) | Хвостовой риск |
| Недавняя активность | Продолжает ли он торговать |

***

## «Реальные результаты копирования» и «Симуляция копирования»

| Тип | Значение |
|------|---------|
| **Copy simulation** | Система проводит бэктест «что было бы, если бы вы копировали» с допущениями о задержке и проскальзывании |
| **Real copy performance** | Данные пользователей, реально копирующих этот адрес на платформе (ROI, P&L копирования, подписчики и т. д.); при недостаточной выборке могут скрываться |

**Ни то, ни другое** не гарантирует ваших результатов после копирования.

***

## Советы по чтению

1. Смотрите на оценку, просадку и пригодность к копированию раньше, чем на общий P&L
2. При слишком малой выборке доля прибыльных сделок и ROI легко искажаются
3. Для адресов маркет-мейкеров / адресов с крайне концентрированными ставками хорошие на вид метрики не означают, что их стоит копировать
4. В конечном счёте оценивайте результаты копирования по собственной **Trade history**
