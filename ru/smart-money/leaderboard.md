# Рейтинг умных денег (фильтр по профилю трейдера)

Рейтинг умных денег помогает находить трейдеров Polymarket, которых стоит копировать. Вход: **Smart money** → `/smart-money` (главная страница приложения теперь — [Рейтинг дневной прибыли копи-пула](copy-pool-board.md); раздел Smart money открывается из меню).

![Рейтинг умных денег](../.gitbook/assets/smarket_doc.png)

***

## Что здесь можно делать

1. **Просматривать рейтинг** — смотреть P&L, оценку, долю прибыльных сделок, результаты за последние 7 дней и другое в виде карточек или таблицы
2. **Искать адреса** — находить трейдера по адресу кошелька
3. **Фильтровать** — категории, быстрые пресеты и расширенные фильтры (уровень, стиль, диапазоны метрик, пригодность к копированию и т. д.)
4. **Выбирать период рейтинга** — Overall / Weekly / Monthly (по умолчанию обычно используется общий рейтинг, который не сортируется просто по общей оценке)
5. **Копировать** — нажмите **Follow** (подписаться), чтобы открыть настройки копирования, или сначала откройте профиль и примите решение там

***

## Как рассчитываются данные рейтинга (обязательно к прочтению)

- Кривые P&L, прибыль за последние 7 дней / общая прибыль и т. д. обычно берутся из официальных данных PnL Polymarket
- Доля прибыльных сделок, профит-фактор и т. д. в основном основаны на **закрытых рынках**
- Оценки и метрики бэктеста основаны на **сделках за недавний период** (около 30 дней / до примерно 4,000 сделок), **а не на всей истории**
- В **отображаемый рейтинг** обычно попадают только адреса, общая оценка которых достигает порога (например, ≥ 40); адреса, которые неоднократно получают низкую оценку, могут из него выбывать
- «Copy fit / backtest P&L / slippage» и подобные показатели — в основном **симуляции с учётом задержки и проскальзывания**, а не реальный P&L пользователей, копирующих на платформе

> Рейтинг **не является инвестиционной рекомендацией**. Прошлые результаты не гарантируют будущей доходности.

## Распространённые фильтры

### Примеры категорий

All, Politics, Sports, Esports, Crypto, Culture, Weather, Economy, Tech, Finance, Mentions и другие.

### Примеры быстрых фильтров

| Пресет | Примерное назначение |
|--------|---------------|
| Featured | Трейдеры, рекомендуемые платформой, преимущественно пригодные к копированию |
| Steady | Относительно консервативный стиль |
| High copyability | За ними легче успевать в симуляции |
| Recently active | Более частая торговля в недавнем периоде |
| All copyable | Адреса, доступные для копирования |
| High win rate / High return / Low drawdown | Сужение выбора по соответствующей метрике |
| Long-term stable | Кандидаты с более высокой стабильностью |

### Расширенные фильтры (распространённые параметры)

- Только адреса, доступные для копирования / только Featured (без маркет-мейкеров)
- Уровень (S–D), стиль торговли
- Диапазоны метрик (например, число сделок за последние 7 дней, доля прибыльных сделок)
- Исключение определённых тегов риска
- Пригодность к копированию: High / Medium / Low

***

## Теги стиля торговли (для справки)

| Тег | Значение (упрощённо) |
|-----|----------------------|
| Information edge | Склонен входить в позиции заранее / торгует на основе информации |
| Arbitrage | Спредовые / арбитражные паттерны |
| Gambler | Паттерны высоковолатильных ставок; копируйте с особой осторожностью |
| Market maker | Высокочастотный маркет-мейкинг; обычно не подходит для обычного копирования |
| Mixed | Общий смешанный стиль |

***

## Рекомендации

1. Начните с пресетов вроде Featured / High copyability / Steady, чтобы сузить выбор
2. Откройте профиль, чтобы изучить факторы оценки, просадку и заметки о рисках
3. Подпишитесь с небольшой суммой для проверки, затем постепенно корректируйте параметры
4. Делясь трейдером, используйте формат ссылки на профиль: `https://app.copyodds.io/@0xADDRESS` (добавьте `/zh` для китайского интерфейса)
