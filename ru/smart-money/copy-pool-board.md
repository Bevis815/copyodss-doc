# Рейтинг (дневная прибыль копи-пула)

**Leaderboard** (рейтинг) — это главная страница приложения (`/`). Он ранжирует аккаунты копи-пула платформы по **дневной прибыли** — по сути, это «табель успеваемости тех, кто в последнее время хорошо копирует».

На странице отображается **дата рейтинга (рабочий день)**; время начала рабочего дня указано на странице.

***

## Что есть на странице

| Элемент | Значение |
|---------|---------|
| **Board · date** | День, за который составлен рейтинг |
| **Daily PnL** | Сколько аккаунт заработал за этот рабочий день |
| **7D** | P&L за последние 7 дней |
| **Current leader / Rank** | Позиция в рейтинге |
| **View analysis / View account** | Переход к подробностям аккаунта |
| **Top N / All N** | Показать только первые несколько позиций или развернуть весь рейтинг |

***

## Как этим пользоваться

1. Откройте приложение — по умолчанию вы попадёте на Leaderboard
2. Сначала посмотрите на **Daily PnL + 7D**; один прибыльный день не означает стабильности
3. Нажмите **View analysis** или **View account**, чтобы увидеть, кого копирует этот аккаунт
4. Если всё устраивает, нажмите **Follow** (подписаться) прямо в рейтинге, чтобы открыть окно настроек копирования

> Аккаунты в рейтинге сами являются копировщиками — их прибыль показывает, что «копирование такого типа трейдеров иногда работает», а не то, что вы заработаете столько же, если будете копировать.

***

## Что нужно помнить

- Рейтинг обновляется ежедневно; вчерашнее место не переносится на сегодня
- На дневную прибыль легко может повлиять одна крупная ставка, поэтому **не смотрите только на №1**
- Чтобы выбирать трейдеров по более точным критериям, используйте фильтры в разделе [Smart money](leaderboard.md)
- Адресами из рейтинга можно делиться напрямую: `https://app.copyodds.io/@0xADDRESS`
