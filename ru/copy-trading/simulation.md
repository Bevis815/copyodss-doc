# Симуляция копи-трейдинга

**Simulation copy trading** (симуляция копи-трейдинга) запускает вашу стратегию копирования на «виртуальном кошельке» — **реальные деньги не используются**, это исключительно для проверки параметров и оценки результатов. Идеально подходит для начинающих, которые пока не готовы вкладывать реальные деньги.

Вход: **Simulation copy trading** → `/copy-trading/simulation`

> Симуляция копи-трейдинга внедряется постепенно. Если вы не видите этого пункта меню, значит, для вас он ещё не включён.

***

## Чем она отличается от реального копирования

| | Симуляция | Реальное копирование |
|--|------------|--------------|
| Деньги | Виртуальный баланс | Ваши кастодиальные USDC |
| Gas | Не нужен | Нужен (около 0.5% сервисной комиссии за сделку) |
| Можно ли потерять деньги? | По-настоящему — нет | Да |
| Назначение | Проверка параметров, оценка долгосрочных результатов | Реальная доходность |

***

## Начните за три шага

### 1. Создайте виртуальный счёт

Нажмите **Create virtual account** и заполните:

| Поле | Описание |
|-------|-------------|
| Название счёта | Что-нибудь, чтобы различать счета, например «Test-A» |
| Начальный баланс | Симулированная основная сумма |
| Длительность (дни) | После истечения срока новые позиции не открываются; существующие позиции по-прежнему можно закрыть или дождаться их расчёта |

### 2. Добавьте адреса для копирования

Добавьте адреса трейдеров в разделе **Copy addresses**; можно задать название стратегии и добавить заметки.

### 3. Настройте стратегию

| Параметр | Описание |
|---------|-------------|
| Способ копирования | Ratio / Fixed amount |
| Направление | Покупка и продажа / только покупка / только продажа |
| Мин. / макс. на сделку | Диапазон суммы для каждой сделки |
| Лимит на рынок | Максимум, который можно вложить в один рынок |
| Дневной лимит | Максимум, который можно вложить за день |
| Макс. проскальзывание | При превышении сделка не исполняется |
| Задержка исполнения | Имитирует «чуть более медленную реакцию» |
| Пауза для рынка | Минимальный интервал между двумя копированиями в одном рынке |
| Пауза после нескольких ошибок подряд | Пауза после указанного числа ошибок подряд (по умолчанию 10) |

Нажмите **Start simulation copy**, чтобы запустить её.

***

## Просмотр результатов: пять вкладок

| Вкладка | Содержимое |
|-----|---------|
| **Copy addresses** | Добавленные вами адреса, настройки стратегии и статус |
| **Positions** | Симулированные позиции; их можно закрыть вручную в режиме симуляции |
| **Executions** | Количество акций, комиссии и статус каждой симулированной сделки |
| **Performance** | Кривая капитала, общий P&L, доля прибыльных сделок, максимальная просадка, затраты на проскальзывание, затраты на комиссии и т. д. |
| **Ledger** | Подробности каждого движения средств |

### Статусы

| Статус счёта | Значение |
|----------------|---------|
| Active | Работает нормально |
| Paused | Вы поставили его на паузу; можно возобновить |
| Expired | Новые позиции не открываются; существующий капитал по-прежнему можно обрабатывать |
| Archived | Убран в архив; пока на счёте есть позиции, архивировать его нельзя |

### Примечание о закрытии позиций

Для ручного закрытия требуется **рыночная цена не старше 15 минут**, чтобы получить котировку; если цена устарела или отсутствует, вам будет предложено обновить котировку. Перед подтверждением вы увидите ожидаемую цену исполнения, проскальзывание, комиссии, ожидаемую выручку и ожидаемый P&L.

***

## Одним предложением

Настоящая ценность симуляции копи-трейдинга в том, что **ещё до вложения реальных денег вы можете увидеть, к чему на самом деле приводит сочетание «частое копирование + высокое проскальзывание + небольшая основная сумма»**.
