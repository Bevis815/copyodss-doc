# Устройства и Passkey

На этой странице рассматриваются две темы безопасности: **с каких устройств выполнялся вход в ваш аккаунт** и **как быстро входить с помощью Face ID / отпечатка пальца**.

Вход: Settings → Security → **Devices** → `/settings/devices`; Passkey управляются в Settings → `/settings/passkeys`

***

## 1. Устройства

### Что вы увидите

| Поле | Значение |
|-------|---------|
| Название устройства | Например, модель телефона или название ОС; если устройство не удаётся определить, отображается «Unknown device» |
| **Current device** | Устройство, которым вы пользуетесь сейчас |
| **Last active** | Когда оно использовалось в последний раз |
| Активные сессии | Сколько сессий входа открыто на этом устройстве |
| Вывод доступен с | Новым устройствам обычно нужно подождать некоторое время, прежде чем с них можно будет выводить средства |

### Удаление устройства

1. Найдите незнакомое устройство → нажмите **Remove**
2. После подтверждения устройство удаляется, и **его сессии входа немедленно аннулируются**

### Когда стоит удалить устройство

- Вы сменили телефон / компьютер, а старое устройство всё ещё в списке
- В истории входов есть устройство, которое вы не узнаёте
- Вы подозреваете, что вашим аккаунтом пользуется кто-то другой

> После удаления на этом устройстве нужно будет войти снова (код по email / Telegram / Passkey).

***

## 2. Passkey

Passkey позволяет входить с помощью **Face ID, отпечатка пальца или блокировки экрана** телефона вместо ввода кода.

### Добавление Passkey

1. Settings → Passkeys → **Add passkey**
2. Пройдите проверку Face ID / отпечатка пальца, следуя подсказкам
3. После этого Passkey появится в списке с указанием времени создания, времени последнего использования и того, синхронизирован ли он

### Вход с его помощью

Выберите **Passkey** на странице входа — email не нужен.

### Удаление Passkey

Выберите его → **Delete** → подтвердите. После удаления с этого устройства больше нельзя будет входить с помощью Passkey.

### Устранение неполадок

| Симптом | Что делать |
|---------|------------|
| При добавлении не появляется Face ID | Отмените и **снова нажмите «Add Passkey»**, пройдя проверку сразу после появления запроса; предварительно закройте баннеры уведомлений |
| Сообщение о том, что устройство не поддерживается | Используйте встроенный системный браузер (Safari на iOS, Chrome на Android) или просто войдите по коду из email |
| Сообщение о том, что Passkey с таким именем уже существует | Сначала удалите старую запись «Android device»; если вы используете прокси / VPN, отключите его и повторите попытку |
| Не удаётся войти | Войдите с помощью кода по email; сбой Passkey не влияет на безопасность вашего аккаунта |

> Passkey можно использовать только для входа, и **его нельзя использовать для подтверждения вывода**.
