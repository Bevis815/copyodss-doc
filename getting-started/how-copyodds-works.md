# CopyOdds 如何运作

从「交易员成交」到「你的账户尝试跟单」，整条链路可以概括为：

```text
聪明钱在 Polymarket 成交
        ↓
CopyOdds 检测到公开成交
        ↓
匹配你对该地址的跟单规则
        ↓
按规则计算下单规模（固定金额或你的余额比例）
        ↓
在滑点范围内尝试下单（消耗平台 Gas）
        ↓
结果写入「交易记录」；持仓反映在「持仓」页
```

## 1. 发现交易员

- 系统对 Polymarket 公开钱包持续评分与筛选
- **展示榜**通常要求综合分达到门槛（如 ≥ 40）；低分地址可能出榜
- 你在 **Smart money** 浏览、搜索，或分析未上榜地址（若功能开放，可能有每日限额）

## 2. 资金与费用分开

| 账户内资源 | 用途 |
|------------|------|
| **USDC（等）** | 跟单本金：买入占用、卖出回笼 |
| **平台 Gas** | 服务费点数：每笔跟单成交按名义金额约 0.5% 扣除 |

Gas 为 0 时：**无法新开 / 恢复跟单**；已有规则通常仍保持运行，但**买单跳过**，有持仓时仍可能跟卖。

## 3. 跟单规则怎么生效

对每个 leader 地址，你保存一套规则（同一地址再保存会覆盖）：

- **跟单方式**：固定 USDC 金额，或按**你自己可用 USDC** 的比例（不是按交易员下单金额等比）
- **方向**：双向 / 只买 / 只卖
- **滑点**：价格偏离过大则不成交
- **最多跟买笔数**：默认 1（不加仓）；可调高，滑到最大为 **All（不限制）**

系统在检测到 leader 成交后按上述规则尝试下单，**不保证**每笔都能跟上。

## 4. 如何判断「跟上了没有」

| 看哪里 | 能说明什么 |
|--------|------------|
| Copy activity（动态） | 交易员做了什么 |
| Trade history（交易记录） | 你的跟单尝试结果（成交 / 跳过 / 失败） |
| Positions（持仓） | 你当前持有什么 |
| My copies（我的跟单） | 规则状态：Following / 手动暂停 / 资金提醒 |

## 5. 充值与提现网络不对称（重要）

- **充值**：Polygon (PoS) 和 BSC（启用时）均可，资产为 USDC / USDT
- **提现**：仅 **Polygon (PoS) USDC**
- 两条充值网络的**地址不同**，切勿混用

详见 [支持的网络](../wallet/supported-networks.md)。

## 6. 安全模型简述

CopyOdds 使用**托管交易账户**：一人一钱包、私钥隔离；提现需 **Authenticator（TOTP）** 二次验证。详见 [安全](../security/wallet-security.md)。
