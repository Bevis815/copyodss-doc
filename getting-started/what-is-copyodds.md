# 什么是 CopyOdds？

CopyOdds 帮你在 Polymarket 上**发现聪明钱交易员，并自动跟单**。

你不需要自己盯盘、手动下单：系统检测到目标交易员在 Polymarket 成交后，会按你设定的规则，在你的 **CopyOdds 交易账户**里尝试镜像下单。

## 适合谁

- 想跟单 Polymarket 上表现较好的钱包，但不想 24 小时手动操作
- 希望用评分、胜率、回撤、可跟性等指标筛选交易员
- 接受**托管交易账户**模式（平台代管钱包，你通过登录与二次验证控制提现）

## CopyOdds 做什么 / 不做什么

| 会做 | 不会做 |
|------|--------|
| 展示聪明钱榜单与交易员画像 | 保证跟单盈利 |
| 按规则自动跟买 / 跟卖 | 完全复刻交易员每一笔的价格与结果（存在延迟、滑点、流动性差异） |
| 提供充值、提现、Gas、持仓与交易记录 | 替你承担预测市场本身的亏损风险 |
| 提供 2FA / Passkey / 提现二次验证等安全能力 | 向你索要助记词或私钥 |

## 核心概念（先记住这 4 个）

1. **聪明钱（Smart Money）** — 经评分与筛选后展示的 Polymarket 交易员地址池
2. **跟单规则（Copy rule）** — 针对某个 leader 地址的一套跟单参数（金额、方向、滑点等）
3. **交易账户** — 托管钱包中的 USDC 等资金，用于实际下单
4. **平台 Gas** — 账户内服务费点数；**不是**链上的 MATIC / BNB
