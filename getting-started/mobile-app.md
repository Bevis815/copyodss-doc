# 手机上怎么用（Mobile App）

CopyOdds 不需要下载也能用；你可以选择最适合自己的方式。

入口：**Mobile App** → `/mobile-app`

***

## 四种使用方式

| 方式 | 说明 | 适合谁 |
|------|------|--------|
| **网页版** | 浏览器直接打开，无需安装 | 桌面用户、临时用一下 |
| **添加到主屏幕（PWA）** | 浏览器里「添加到主屏幕」，有全屏体验和推送 | 大多数手机用户（推荐） |
| **Telegram 小程序** | 在 Telegram 内直接打开 | 一直在 Telegram 里的人 |
| **Android App** | 从 Google Play 下载 | 想要更接近原生的体验 |

支持的设备：iPhone / iPad（Safari）、Android（Chrome）、Windows 与 Mac（Chrome / Edge）。

***

## 推荐：添加到主屏幕（PWA）

CopyOdds 是一个 PWA（渐进式网页应用），**不用去应用商店下载**，装到桌面后：

- **全屏显示**，没有浏览器地址栏
- **桌面图标一键打开**
- **可以接收推送提醒**，即使 App 关着也能收到跟单提醒

### 怎么装

- **iPhone / iPad**：用 Safari 打开官网 → 分享 → **添加到主屏幕**
- **Android**：用 Chrome 打开官网 → 菜单 → **安装应用 / 添加到主屏幕**

装好后如果提示「已安装」，说明你之前装过，直接从桌面图标打开即可。

## Android App

在 **Mobile App** 或 **设置 → 版本** 页面可以看到：

- 当前 App 版本
- 是否有新版本（**Update Available** / **Up to date**）
- 前往 Google Play 的下载入口，以及该版本的更新说明

| 位置 | 内容 |

| 底部标签栏 | 排行榜 / 聪明钱 / 我的跟单 / 充值 |

## 常见问题

**一定要下载 App 吗？**  
不需要。网页版功能是完整的。

**装了之后收不到推送？**  
确认手机系统里允许该应用发送通知；iOS 需在系统设置中为对应 App 打开通知权限。

**换手机了怎么办？**  
在新设备上重新登录（邮箱验证码 / Telegram / Passkey），再到 [设备管理](../account/devices-and-passkeys.md) 把旧设备移除。
