# 界面导航一览

第一次打开 App 会有点不知道该点哪里。这一页把每个入口都用大白话说一遍，你照着找就行。

> 提示：手机底部有 4 个常用标签（**排行榜 / 聪明钱 / 我的跟单 / 充值**），其他功能在左上角菜单里；电脑端在左侧边栏。

***

## 一、主要功能（左侧边栏上半部分）

| 菜单名 | 中文叫法 | 什么时候用 |
|--------|----------|------------|
| **Leaderboard** | 排行榜 | 想知道平台跟单池里今天谁赚得最多，从这里挑人 |
| **Smart money** | 聪明钱 | 想按评分、回撤等条件筛选交易员 |
| **My copy trading** | 我的跟单 | 管理你已经开启的跟单规则（暂停、恢复、改设置） |
| **Simulation copy trading** | 模拟跟单 | 想先不用真钱试一下跟单效果 |
| **Store** | Gas 商城 | 买平台 Gas（服务费点数） |
| **My positions** | 我的持仓 | 看你现在持有哪些市场、成本多少、赚没赚 |
| **Executions** | 交易记录 | 看你每一笔跟单的尝试结果（成交 / 跳过 / 失败） |
| **Affiliation** | 邀请返佣 | 邀请朋友一起用，赚佣金 |

***

## 二、资金与设置（左侧边栏下半部分）

| 菜单名 | 中文叫法 | 什么时候用 |
|--------|----------|------------|
| **Deposit** | 充值 | 把链上的 USDC / USDT 转入平台 |
| **个人中心** | Profile | 一屏看完 Gas 余额、钱包余额，并可直达邀请页 |
| **Withdraw** | 提现 | 把 USDC 提回你自己的钱包地址 |
| **Settings** | 设置 | 语言、通知、账号绑定、安全状态、App 版本 |
| **Mobile App** | 移动端下载 | 装到手机桌面 / 下载 App |
| **User guide** | 用户指南 | 就是你正在看的这份文档 |

***

## 三、几个容易搞混的页面

| 页面 | 一句话区分 |
|------|-----------|
| **排行榜** | 看的是「跟单池账户」的当日盈利排名 |
| **聪明钱** | 看的是单个交易员地址的评分、胜率、回撤等画像 |
| **我的持仓** | 看的是**你现在持有**什么 |
| **交易记录** | 看的是**系统替你下过的每一单**结果 |
| **跟单动态** | 看的是**交易员**刚做了什么，以及你有没有跟上 |
| **资金流水** | 看的是**钱的进出**（充值、提现、Gas 消费） |
| **个人中心** | 看的是**你的资产总览**和邀请入口 |

***

## 四、建议的使用顺序

1. **登录**
2. **充值**
3. **买 Gas**
4. **挑人（排行榜 / 聪明钱）**
5. **点 Follow 跟单**（默认「比例」模式）
6. 回到 **我的跟单** 确认状态是「跟单中」

详见 [快速开始](quick-start.md)。
