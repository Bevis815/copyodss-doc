# 什么是 Polymarket？

[Polymarket](https://polymarket.com) 是全球知名的**预测市场**平台：用户对真实世界事件（选举、体育、加密、经济数据等）的结果买卖份额，价格反映市场对该结果发生概率的看法。

## 和传统交易有什么不同

- 交易的是事件结果份额（例如 Yes / No），不是股票或合约标的本身
- 价格通常在 0–1 美元区间波动，可粗略理解为「市场隐含概率」
- 事件结算后，正确结果的份额可按规则兑付

## 和 CopyOdds 的关系

CopyOdds **不替代** Polymarket，而是：

1. 分析链上 / 公开成交中表现较好的钱包（聪明钱）
2. 在你授权并开通的 CopyOdds 交易账户上，自动镜像这些钱包的成交

因此你会看到两类信息：

| 来源 | 含义 |
|------|------|
| Polymarket 公开数据 / 榜单指标 | 交易员自己的历史表现（参考） |
| CopyOdds 交易记录 / 持仓 | **你的账户**实际跟单结果 |

> 榜单上的盈亏、胜率、仿真跟单指标 **≠** 你跟单后的真实盈亏。请以 App 内「交易记录 / 持仓」为准。

## 风险提示

预测市场波动大，跟单可能因滑点、延迟、资金不足、流动性等原因失败或与交易员结果不一致。请只投入可承受损失的资金。
