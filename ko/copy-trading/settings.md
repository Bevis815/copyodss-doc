# 카피 설정

카피 마법사의 각 매개변수가 의미하는 바를 설명합니다. 마법사에 표시되지 않는 항목(일부 일일 한도나 지연 등)은 현재 앱 인터페이스를 기준으로 하세요. 이전 문서의 고급 한도는 통합되었을 수 있습니다.

***

## 기본 설정

| 설정 | 설명 |
|---------|-------------|
| **Leader address** | 카피할 지갑 주소. 정확해야 함 |
| **Name** | 규칙의 표시 이름, 선택 사항 |
| **Copy mode** | 하나 선택: **Ratio** (기본값) / **By balance %** / **Fixed amount** |
| **Copy ratio** | Ratio 모드 전용: 리더의 체결 금액 × 비율 = 내 주문 금액 |
| **Slippage tolerance** | 트레이더의 체결 가격에서 허용되는 편차. 기본값 **15%**, 1%에서 100%까지 조정 가능 |

### 슬리피지에 대한 사고방식

슬리피지를 **너무 좁게** 설정하면: 가격이 움직일 때 건너뛰거나 실패할 가능성이 높아집니다.  
슬리피지를 **너무 넓게** 설정하면: 체결될 가능성이 높아지지만, 더 나쁜 가격에 체결될 수 있습니다.  
기본값 15%는 체결률을 높이기 위한 것이며, 자신의 위험 성향에 맞게 조정하세요. Ratio 모드에는 "Leader order size range"와 "Copy ratio"라는 두 가지 추가 매개변수도 있습니다 — [세 가지 카피 모드](copy-modes.md)를 참조하세요.

***

## Ratio 모드 매개변수

| 설정 | 설명 |
|---------|-------------|
| **Copy ratio** | 0.1%–100%. 페이지에 "하루 약 N건 거래"와 함께 권장값이 표시됨 |
| **Leader order size range** | 리더의 과거 최대 체결 금액에서 산출됨. 하한 미만은 건너뛰고, 상한 초과는 "상한 × 비율"로 계산됨 |

전체 설명과 예시는 [세 가지 카피 모드](copy-modes.md)를 참조하세요.

***

## 고급 설정

| 설정 | 설명 |
|---------|-------------|
| **Direction · Both sides** | 매수와 매도 모두 카피 |
| **Direction · Buy only** | 매수만 카피 |
| **Direction · Sell only** | 매도만 카피 |
| **Max open copy buys** | 같은 규칙에서 동시에 보유할 수 있는 최대 카피 매수 수. **기본값 1 = 포지션 추가 없음**. 최대값은 **All = 무제한**으로 표시됨 |

### 기본적으로 포지션을 추가하지 않는 이유는?

단일 예측 마켓의 포지션은 빠르게 쌓일 수 있습니다. 기본값 1은 단일 마켓 위험을 제한하는 데 도움이 되며, 전략이 자신에게 맞는다는 것을 확인한 후 늘리세요.

***

## 플랫폼 기본 동작 (알아 두면 좋은 점)

- **카피 지연**: 현재 제품은 보통 즉시 시도합니다 (추가적인 인위적 지연 없음)
- **연속 실패 후 일시 중지**: 반복적으로 실패하면 플랫폼이 잠시 매수를 일시 중지할 수 있습니다 (정확한 기준은 다를 수 있음). 문제를 해결한 후 **My copies** (내 카피)에서 재개할 수 있습니다

***

## 자금 관련 "소프트 한도"

반드시 설정 항목은 아니지만 한도처럼 작용합니다:

| 상황 | 영향 |
|-----------|--------|
| Gas = 0 | 매수가 건너뛰어짐. Gas를 구매하고 **Resume buys** (매수 재개)를 탭하세요 |
| USDC 부족 | 매수가 건너뛰어짐. 더 입금하거나 금액 / 비율을 낮추세요 |
| 약 $1 미만 | 매수가 거래소의 최소 주문 금액을 충족하지 못할 수 있음 |

***

## 설정 변경

1. **My copies**를 엽니다
2. 규칙 찾기 → **Edit** (편집)
3. 저장한 후에는 이후의 체결에만 영향을 줍니다

사용 중인 환경에서 Simulation이 활성화되어 있다면 더 많은 한도형 매개변수가 표시될 수 있습니다. 실제 카피에서는 마법사의 항목이 기준입니다.

***

## Quick copy 페이지의 항목

트레이더 프로필에서 카피를 시작하는 것 외에도, **Quick copy** 페이지(`/copier`)에서 주소를 직접 붙여넣을 수도 있습니다:

| 항목 | 설명 |
|-------|-------------|
| **Copy ratio** | 사용 가능 잔액의 비율로 팔로우. 100%는 전체 잔액을 사용하고, 5%는 가벼운 포지션 |
| **Per-trade cap (USDC)** | 단일 거래에 넣을 최대 금액 |
| **Total cap (USDC)** | 모든 카피를 합쳐 넣을 최대 금액 |
| **Auto-copy toggle** | 켜면 시스템이 수탁형 지갑을 사용해 이 사용자의 주문을 자동으로 카피 |

같은 주소를 다시 설정하면 이전 규칙을 **덮어씁니다**. 변경한 후에는 **My copies**에서 한 번 확인하세요.
