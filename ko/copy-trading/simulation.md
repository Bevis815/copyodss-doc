# 시뮬레이션 카피 트레이딩

**시뮬레이션 카피 트레이딩**은 "가상 지갑"으로 카피 전략을 실행합니다 — **실제 자금이 전혀 들지 않으며**, 순수하게 매개변수를 테스트하고 결과를 확인하기 위한 것입니다. 아직 실제 자금을 넣을 준비가 되지 않은 초보자에게 이상적입니다.

진입점: **Simulation copy trading** → `/copy-trading/simulation`

> 시뮬레이션 카피 트레이딩은 단계적으로 제공되고 있습니다. 이 메뉴가 보이지 않는다면 아직 활성화되지 않은 것입니다.

***

## 실제 카피와의 차이점

| | 시뮬레이션 | 실제 카피 |
|--|------------|--------------|
| 자금 | 가상 잔액 | 수탁형 지갑의 USDC |
| Gas | 필요 없음 | 필요함 (거래당 약 0.5% 서비스 수수료) |
| 돈을 잃을 수 있나요? | 실제로는 아니요 | 네 |
| 용도 | 매개변수 테스트, 장기 성과 확인 | 실제 수익 |

***

## 세 단계로 시작하기

### 1. 가상 계정 만들기

**Create virtual account** (가상 계정 만들기)를 탭하고 다음을 입력합니다:

| 항목 | 설명 |
|-------|-------------|
| 계정 이름 | 구분하기 위한 이름, 예: "Test-A" |
| 시작 잔액 | 시뮬레이션 원금 |
| 기간 (일) | 만료 후에는 새 포지션을 열지 않음. 기존 포지션은 여전히 청산하거나 정산할 수 있음 |

### 2. 카피할 주소 추가

**Copy addresses**에서 트레이더 주소를 추가합니다. 전략 이름을 지정하고 메모를 추가할 수 있습니다.

### 3. 전략 구성

| 설정 | 설명 |
|---------|-------------|
| 카피 방식 | Ratio / Fixed amount |
| 방향 | 매수 및 매도 / 매수만 / 매도만 |
| 거래당 최소 / 최대 | 각 거래의 금액 범위 |
| 마켓당 한도 | 단일 마켓에 넣을 최대 금액 |
| 일일 한도 | 하루에 넣을 최대 금액 |
| 최대 슬리피지 | 초과하면 체결하지 않음 |
| 실행 지연 | "조금 늦게 반응하는" 상황을 시뮬레이션 |
| 마켓 쿨다운 | 같은 마켓에서 두 번의 카피 사이의 최소 간격 |
| 연속 실패 후 일시 중지 | 연속으로 이 횟수만큼 실패하면 일시 중지 (기본값 10) |

**Start simulation copy** (시뮬레이션 카피 시작)를 탭하여 실행합니다.

***

## 결과 보기: 다섯 개의 탭

| 탭 | 내용 |
|-----|---------|
| **Copy addresses** | 추가한 주소, 전략 설정, 상태 |
| **Positions** | 시뮬레이션 포지션. 수동으로 청산을 시뮬레이션할 수 있음 |
| **Executions** | 각 시뮬레이션 체결의 지분 수, 수수료, 상태 |
| **Performance** | 자산 곡선, 총 손익, 승률, 최대 낙폭, 슬리피지 비용, 수수료 비용 등 |
| **Ledger** | 모든 자금 이동의 상세 내역 |

### 상태

| 계정 상태 | 의미 |
|----------------|---------|
| Active | 정상 실행 중 |
| Paused | 일시 중지함. 재개 가능 |
| Expired | 새 포지션 없음. 기존 자산은 여전히 처리 가능 |
| Archived | 보관됨. 포지션을 보유하는 동안에는 보관할 수 없음 |

### 포지션 청산 시 참고 사항

수동으로 청산하려면 견적을 받기 위해 **최근 15분 이내의 시장 가격**이 필요합니다. 가격이 오래되었거나 없으면 견적을 새로고침하라는 안내가 표시됩니다. 확인하기 전에 예상 체결 가격, 슬리피지, 수수료, 예상 수익금, 예상 손익을 볼 수 있습니다.

***

## 한 문장으로

시뮬레이션 카피 트레이딩의 진짜 가치는 이것입니다: **실제 자금을 쓰기 전에 "잦은 카피 + 높은 슬리피지 + 적은 원금"이 실제로 어떤 결과로 이어지는지 확인할 수 있다는 것.**
