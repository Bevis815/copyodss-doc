# 내 포지션 및 거래 내역

카피를 시작하면 모든 포지션과 각 주문의 결과는 이 두 페이지에 있습니다. **초보자라면 이 두 페이지만 알면 충분합니다.**

| 페이지 | 진입점 | 답해 주는 질문 |
|------|-------|-----------------|
| **My positions** | My positions → `/executions/positions` | 지금 무엇을 보유하고 있으며, 수익인가요 손실인가요? |
| **Trade history** | Executions → `/executions/records` | 모든 카피 시도의 결과 |
| **Profit/Loss** | Executions → Profit/Loss → `/executions/daily-pnl` | 이 기간 동안 얼마를 벌었나요? |

***

## 내 포지션

### 보게 될 항목

| 항목 | 의미 |
|-------|---------|
| **Market / Outcome** | 어떤 사건의 어떤 결과(Yes / No)를 매수했는지 |
| **Avg. price / Current price** | 내 진입 원가와 현재 시장 가격 |
| **Cost / Value / P&L** | 얼마를 썼는지, 지금 가치는 얼마인지, 수익인지 |
| **Copy sources** | 어떤 카피 규칙으로 이 포지션이 쌓였는지 |
| **Status** | Open / Pending settlement / Settled / Archived |

### 할 수 있는 일

| 작업 | 설명 |
|--------|-------------|
| **Buy more** | USD 금액을 입력하여 직접 조금 더 매수 |
| **Close** | 시장가로 매도하여 손익 확정. 가격은 시장에 따라 움직임 |
| **Bulk close** | 일정 수의 포지션을 한 번에 청산 |
| **Redeem** | 마켓이 종료되고 이겼을 때 — 포지션을 USDC로 전환 |
| **View details** | 매수 시각, 정산 방식, 전체 타임라인 보기 |

### 상태의 의미

| 상태 | 설명 |
|--------|-------------|
| **Open** | 마켓이 아직 종료되지 않음. 매도 가능 |
| **Pending settlement** | 당분간 매도 불가. 이겼다면 Redeem이 나타나고, 졌다면 자동으로 종료됨 |
| **Settled** | USDC로 전환되어 잔액으로 돌아옴 |
| **Archived** | 당분간 매도할 수 없는 아주 작거나 유동성이 없는 포지션. 다른 것에는 영향 없음 |

## 거래 내역 (카피 기록)

각 행은 시스템이 나를 대신해 수행한 시도 1건입니다:

| 상태 | 의미 |
|--------|---------|
| **Filled** | 성공적으로 카피됨 |
| **In progress** | 아직 처리 중 |
| **Skipped** | 주문하지 않음 (실패 사유 참조) |
| **Failed** | 주문이 거부되거나 오류가 발생함 |

**Filled / Settled / Unsuccessful**로 필터링할 수 있습니다. 아무 행이나 탭하면 다음을 볼 수 있습니다: 카피 규칙, 주문 ID, 매수 가격 및 지분 수, 종료 방식(매도 / 상환 / 만료), 원가, 수익금, 손익, 전체 타임라인, 온체인 해시.

## Profit/Loss 페이지

- 상단에는 **누적 손익 곡선**이 표시되며, 1일 / 1주 / 1개월 등으로 전환할 수 있습니다
- 하단에는 오늘, 어제, 각 날짜의 계정 손익 변화를 포함한 **기간별 내역**이 표시됩니다
- 곡선은 Polymarket의 계정 손익 방법론과 일치합니다. 공식 데이터를 일시적으로 사용할 수 없으면 페이지에 대신 플랫폼 원장 데이터를 사용하고 있다고 표시됩니다

> 영업일의 시작 시각은 페이지에 표시된 대로이므로 (예: 08:00 시작), 여러 날에 걸친 데이터를 볼 때 이 점을 유의하세요.

## 초보자가 자주 묻는 질문

**포지션의 손익이 잔액과 맞지 않는 이유는 무엇인가요?**  
포지션 손익은 "현재 시장 가격으로 추정한" 값이며, 미실현 부분은 가격에 따라 변합니다. 잔액에는 매도하거나 상환한 후에야 반영됩니다.

**매도가 실패한 이유는 무엇인가요?**  
흔한 이유: 그 시점에 마켓에 매수 주문이 없음, 지분이 미체결 주문에 묶여 있음, 또는 남은 포지션이 최소 매도 규모보다 작음. 나중에 다시 시도하세요.

**이겼는데 왜 돈이 보이지 않나요?**  
마켓이 정산된 후 입금되기까지 약간의 시간이 걸립니다. **Redeem** (상환)을 탭하여 수동으로 상환할 수 있습니다. "Pending settlement"로 표시되는 동안에는 아직 조치할 수 없습니다.
