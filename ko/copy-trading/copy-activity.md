# 카피 활동

**Copy activity** (카피 활동)는 두 가지를 알려 줍니다: **트레이더가 방금 한 일**, 그리고 **내가 그것을 카피했는지**.

진입점: **Copy activity** → `/feed` (보통 **My copies** 또는 메뉴에서 접근)

***

## 페이지 구성

1. **상단: 내가 카피 중인 지갑** — 카피를 활성화한 주소 목록. 하나를 탭하면 해당 주소만 표시됩니다
2. **세 개의 탭**

| 탭 | 내용 |
|-----|---------|
| **Activity** | 트레이더의 공개 매수 / 매도 |
| **My orders** | 시스템이 나를 대신해 넣은 각 주문의 결과 |
| **My positions** | 현재 포지션과 손익 |

3. **필터**: All / Successful / Buys / Sells / Copying
4. 모든 항목에는 시간(**just now**, **a few minutes ago**)이 표시됩니다. 모바일에서는 아래로 당겨 새로고침하세요

***

## 카피 상태 읽기

| 상태 | 의미 | 해야 할 일 |
|--------|---------|------------|
| **Copying** | 주문을 넣으려고 시도 중 | 잠시 기다리기 |
| **Copied** | 성공적으로 카피됨 | 없음 |
| **Skipped** | 이번에는 카피되지 않음 | 실패 사유 확인 |
| **Failed** | 주문이 거부되거나 오류가 발생함 | 사유 확인 — 잔액 / 슬리피지 / Gas 문제일 수 있음 |
| **Not copied** | 이 항목은 내 카피 범위에 속하지 않음 | 없음 |

아무 항목이나 탭하면 **거래 상세 정보**를 볼 수 있습니다: 마켓, 방향, 주소, 거래량, 카피 규칙, 카피 지갑, 상태, 시간, 온체인 트랜잭션 해시.

***

## 흔한 건너뜀 사유

- 방향 불일치 (Buy only / Sell only로 설정함)
- 금액이 너무 작음 (거래소 최소 매수 금액 약 $1 미만)
- "Max open copy buys" 도달 (기본값 1, 즉 포지션 추가 없음)
- 슬리피지가 너무 큼
- **Gas 부족** 또는 **USDC 부족**
- 트레이더가 매도했지만 내가 해당 포지션을 보유하고 있지 않음
- 그 시점에 해당 마켓에서 주문을 받는 사람이 없었음

***

## 팁

- **Activity**로 다른 사람을 지켜보고 **Trade history**로 나 자신을 확인하세요 — 두 가지를 비교하는 것이 문제를 찾는 가장 쉬운 방법입니다
- 건너뜀이 많다면 먼저 Gas와 잔액을 확인한 후, 슬리피지 조정이나 금액 낮추기를 고려하세요
- 고객 지원에 항목을 공유할 때는 **기록 ID** 또는 **트랜잭션 해시**를 포함하세요
