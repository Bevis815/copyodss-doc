# 카피 관리

모든 카피 규칙은 **My copies** (내 카피) → `/copy-rules`에서 관리합니다.

![내 카피](../.gitbook/assets/my_copies_doc.png)

***

## 페이지 상단 요약 (일반적인 항목)

| 항목 | 의미 |
|-------|---------|
| Realized | 청산된 포지션에서 실현된 손익 |
| Position | 현재 포지션 시장 가치 요약 |
| Unrealized | 평가 손익 |
| Win Rate | 승 / 패 통계 |

아직 규칙을 만들지 않았다면 페이지에 시작 가이드가 표시될 수 있습니다: 로그인 → 입금 → Gas 구매 → 카피 시작.

***

## 규칙 상태

| 상태 | 의미 | 해야 할 일 |
|--------|---------|------------|
| **Following** (팔로우 중) | 정상적으로 카피 중 | Trade history만 지켜보면 됨 |
| **Manually paused** (수동 일시 중지) | 직접 일시 중지함 | 필요할 때 재개 |
| **Funding alert** (자금 알림) | 자금 / Gas 문제로 매수에 영향이 있음 | 입금하거나 Gas를 구매한 후 **Resume buys** (매수 재개) 탭 |

> 자금이 부족하면 규칙은 **대개 켜진 상태로 유지되고** 매수만 건너뛰어집니다. 이는 의도된 설계로, 충전 후에도 기존 포지션의 매도를 계속 카피할 수 있도록 하기 위함입니다.

***

## 개별 규칙에 대한 작업

| 작업 | 설명 |
|--------|-------------|
| Pause / Resume | 규칙 전체를 일시 중지하거나 재개 |
| Resume buys | 자금 알림을 해제하고 매수 카피를 계속 |
| Edit | 금액, 비율, 슬리피지 등 변경 |
| Delete | 규칙 삭제 (기록은 보통 유지됨) |
| Positions / Activity / Detail | 포지션, 활동 또는 프로필로 이동 |

일괄 일시 중지 / 재개 / 삭제도 지원됩니다 (UI 참조).

***

## 일시 중지 vs. 삭제

| | 일시 중지 | 삭제 |
|--|-------|--------|
| 나중에 빠르게 복원할 수 있나요? | 네, Resume | 규칙을 다시 만들어야 함 |
| 거래 내역 | 유지됨 | 보통 유지됨 |
| 기존 포지션 | 자동으로 매도되지 **않음** | 자동으로 매도되지 **않음** |

포지션은 **Positions**에서 직접 청산하거나, 정산을 기다린 후 상환하세요.

***

## 관련 페이지

| 페이지 | 경로 | 용도 |
|------|------|---------|
| Copy activity | `/feed` | 리더의 공개 체결과 카피 상태 태그 보기 |
| Trade history | `/executions/records` | 내 체결 결과 |
| Positions | `/executions/positions` | 포지션 및 청산 |
| Daily P&L | `/executions/daily-pnl` | 일일 실현 손익 |

![카피 활동](../.gitbook/assets/feed_doc.png)

Copy activity의 상태 태그는 "이 공개 체결에 대해 카피를 시도했는지"를 이해하는 데 도움이 되지만, **최종 판단 기준은 Trade history입니다**.
