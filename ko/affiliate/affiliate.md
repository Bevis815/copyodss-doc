# 제휴 프로그램 (Affiliation)

친구에게 초대 링크를 공유하세요 — 친구가 가입하고 구매하면 커미션을 받습니다.

진입점: **Affiliation** → `/affiliate`

***

## 페이지 구성

| 섹션 | 설명 |
|---------|-------------|
| **Invite link / Invite code** (초대 링크 / 초대 코드) | 링크나 코드를 복사해 친구에게 보내세요. 내 링크로 가입하면 자동으로 나와 연결됩니다 |
| **Current commission rate** (현재 커미션 비율) | 내 등급에 따라 결정됨. [커미션 등급](commission-tiers.md) 참조 |
| **Invited users / Estimated earnings** (초대한 사용자 / 예상 수익) | 요약 데이터 |
| **Referral list** (추천 목록) | 사용자 ID나 초대 코드로 검색하여 추천인의 등급과 기여도 확인 |
| **Telegram bot link** (Telegram 봇 링크) | 팀이 전용 봇을 배정한 경우 표시됨. 그렇지 않으면 웹 초대 링크를 사용하세요 |
| **Auto-upgrade progress** (자동 업그레이드 진행 상황) | 다음 등급까지 필요한 직접 추천 인원 수 |

***

## 첫 커미션을 받는 방법

1. 아무 구매나 합니다 (Gas 패키지 또는 커미션 등급) → **L1이 자동으로 활성화됩니다**
2. 초대 링크를 복사해 친구에게 보냅니다
3. 친구가 링크를 통해 가입합니다
4. 친구가 구매합니다 → 현재 등급의 비율로 커미션을 받습니다

> 커미션은 추천인의 거래 수익이 아니라 **추천인의 패키지 구매**에서 발생합니다. 추천인의 거래 손실은 내 커미션에 영향을 주지 않습니다.

***

## 등급 업그레이드

등급은 추천 인원 수에 따라 **자동으로 업그레이드되며**, 신청할 필요가 없습니다. 최상위 등급은 **Upgrade commission tier** (커미션 등급 업그레이드) 페이지에서 구매해야 합니다. [커미션 등급 및 업그레이드](commission-tiers.md)를 참조하세요.

***

## 자주 묻는 질문

**초대 코드가 아직 나타나지 않나요?**  
초대 코드 생성에는 잠시 시간이 걸립니다 — 페이지를 새로고침하세요. 그래도 나타나지 않으면 고객 지원에 문의하세요.

**친구가 가입했는데 내 추천인으로 집계되지 않나요?**  
친구가 내 링크 / 초대 코드를 통해 가입했는지 확인하세요. 다른 방법으로 이미 가입한 계정은 소급하여 연결할 수 없습니다.

**커미션은 언제 정산되나요?**  
페이지에 표시된 기록을 기준으로 하세요. 정산은 등급 규칙에 따라 다릅니다.

**계정 보안에 영향이 있나요?**  
제휴 기능은 비밀번호나 인증 코드를 넘겨 달라고 요구하지 않습니다. **인증 코드를 요구하거나 코드를 이용한 "동결 해제"를 제안하는 사람은 사기꾼입니다.**
