# 출금 보안

출금은 자금을 외부 주소로 옮기는 것이므로, 모든 출금에는 **추가 인증**이 필요합니다. 현재는 **Authenticator (TOTP)** 방식만 지원됩니다.

![출금 추가 인증](../.gitbook/assets/withdraw_stepup_doc.png)

***

## 인증 방법

- **유일한 방법: Authenticator 코드** (Google / Microsoft Authenticator, 1Password 등)
- Authenticator가 연동되어 있지 않으면, 출금 절차에서 먼저 설정에서 활성화하라고 요청합니다
- **Passkey와 이메일 인증 코드는 출금에 사용할 수 없습니다** (로그인 등에는 여전히 사용 가능)

설정에서 "출금 추가 인증" 설명을 확인할 수 있습니다.

***

## 출금할 때 해야 할 일

1. Authenticator가 연동되어 있는지 확인합니다
2. 출금 페이지에 Polygon 주소와 금액을 입력하고 다시 확인합니다
3. 추가 인증 대화상자에 6자리 코드를 입력합니다
4. 인증이 통과되면 출금을 제출합니다

코드가 틀렸거나 만료되었다면 현재 코드를 다시 입력하기만 하면 됩니다.

***

## 추가 보호 장치

| 메커니즘 | 설명 |
|-----------|-------------|
| 최대 출금 가능 금액 | 포지션과 주문에 묶인 자금은 출금할 수 없음 |
| 새 기기 / 새 네트워크 대기 시간 | 기기를 바꾸거나 IP가 변경된 후에는 일시적으로 출금할 수 없을 수 있음 |
| 출금 채널 혼잡 | 사용량이 많은 시간에는 몇 분에서 몇 시간까지 기다려야 할 수 있음. 자금은 안전함 |
| 받는 지갑에 MATIC 필요 | 새 주소에 약간의 MATIC (POL)을 보관하세요. 그렇지 않으면 이후 이 USDC를 온체인에서 옮길 수 없음 |
| 거래 제한 | 계정의 거래가 제한되면 출금도 영향을 받을 수 있음 |
| 주소 확인 | 잘못된 외부 주소로 보낸 자금은 보통 복구할 수 없음 |

***

## 안전 팁

- 고객 지원이라고 주장하는 사람에게 Authenticator 코드를 절대 알려 주지 마세요
- 누군가 알려 준 "중간 주소"로 출금 주소를 절대 바꾸지 마세요
- 공식 이메일 도메인 안내는 [피싱 방지](anti-phishing.md)를 참조하세요
- 큰 금액을 출금하기 전에: 소액으로 테스트 → 도착 확인 → 그다음 더 출금하세요
