# 2단계 인증 (2FA)

CopyOdds는 기본적으로 **이메일 인증 코드**로 로그인합니다 (기존 방식의 비밀번호 없음). 출금 보안과 로그인 보안을 각각 강화하기 위해 Authenticator와 Passkey를 모두 활성화하는 것을 권장합니다.

![보안 설정](../.gitbook/assets/settings_security_doc.png)

***

## 사용 가능한 방법

| 방법 | 용도 |
|--------|---------|
| **이메일 OTP** | 로그인, 연동 인증 |
| **Authenticator (TOTP)** | **출금 추가 인증 (유일한 방법)**. 계정 보안도 강화함 |
| **Passkey** | 얼굴 / 지문 / 화면 잠금으로 빠른 **로그인** 인증 |
| **Telegram** | 선택적 로그인 / 연동 방법 (설정 참조) |
| **기기 관리** | 기기 보기 및 제거. 새 기기는 출금에 영향을 줄 수 있음 |

***

## 권장 설정 순서

1. 이메일을 연동하고 인증합니다
2. **Authenticator를 활성화합니다 (출금 전 필수)**
3. 자주 사용하는 기기에 **Passkey**를 추가합니다 (더 쉬운 로그인을 위해)
4. **Devices** (기기) 목록에 익숙해지고 알아볼 수 없는 기기는 제거합니다

***

## Authenticator (TOTP)

1. **Settings → Security** (설정 → 보안)를 엽니다
2. 안내에 따라 Authenticator 앱으로 QR 코드를 스캔하거나 키를 직접 입력합니다
3. 6자리 코드를 입력하여 활성화를 완료합니다

출금 절차에서 이곳으로 왔다면, 완료 후 **자동으로 지갑 페이지로 돌아가 출금을 계속할 수 있습니다**.

### Authenticator 끄기

보안을 위해 **끌 때도 6자리 코드가 필요합니다**. 기기만 바꾸려는 경우 새 기기에서 다시 연동하는 것이 더 간편합니다.

### 자주 보는 메시지

| 메시지 | 원인 | 해야 할 일 |
|---------|-------|------------|
| 코드가 틀렸거나 만료됨 | 오타 또는 30초 이상 경과 | 새 코드를 기다렸다가 입력 |
| 이미 사용된 코드 | 같은 코드를 두 번 제출함 | 다음 새 코드를 기다리기 |
| 연동 만료 | 스캔과 확인 사이에 시간이 너무 오래 걸림 | 연동을 다시 시작 |
| 시도 횟수 초과 | 짧은 시간에 잘못 입력한 횟수가 너무 많음 | 잠시 기다린 후 다시 시도 |
| Authenticator가 이미 활성화됨 | 두 번째로 연동하려 함 | 다시 할 필요 없음 |

***

## Passkey

1. 지원되는 브라우저 / OS에서 설정을 엽니다
2. Passkey를 추가하고 안내에 따라 생체 인증 또는 화면 잠금 인증을 완료합니다
3. 로그인 페이지에서 Passkey를 선택하여 빠르게 로그인할 수 있습니다

참고: Passkey는 출금 확인에 사용할 수 **없습니다**. 지원 여부는 브라우저, WebView, OS 버전에 따라 다르며, 로그인에 실패하면 이메일 인증 코드를 사용하세요.

***

## 기기 및 세션

- 로그인한 기기는 `/settings/devices`에서 확인하세요
- 새 기기나 환경에서 로그인한 후에는 한동안 **출금이 일시적으로 잠길 수 있습니다** (보안 대기 시간)
- 공용 컴퓨터에서는 알 수 없는 확장 프로그램을 장기간 신뢰하거나 안전하지 않은 곳에 코드를 저장하지 마세요

***

## Authenticator를 분실하셨나요?

아직 이메일에 접근할 수 있다면:

1. 이메일 인증 코드로 로그인합니다
2. 설정에서 Authenticator (및 필요한 Passkey)를 다시 연동합니다
3. 기기 목록을 확인하고 분실한 기기를 제거합니다

이메일에도 접근할 수 없다면: 고객 지원에 문의하고 신원 확인 자료를 준비하세요 (고객 지원 절차에 따름).
