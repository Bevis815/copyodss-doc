# 지갑 보안

CopyOdds는 **수탁형 거래 계정** 모델을 사용합니다. 거래용 개인 키를 직접 보관할 필요는 없지만, 로그인 수단과 출금 인증은 직접 보호해야 합니다.

앱의 전체 설명: **Asset security guarantee** (자산 보안 보장) → `/wallets/security`.

![자산 보안 보장](../.gitbook/assets/wallet_security_doc.png)

***

## 핵심 메커니즘

| 기능 | 설명 |
|------------|-------------|
| **전용 지갑** | 사용자마다 별도의 수탁형 지갑이 있으며, 자산은 격리되어 관리됨 |
| **개인 키 격리** | 지갑 개인 키는 별도로 암호화 및 격리되며, 일상적인 거래 인터페이스에 직접 노출되지 않음 |
| **출금 보호** | 출금에는 추가 인증이 필요함. 주요 보안 설정을 변경하면 재인증 / 대기 시간이 적용될 수 있음 |

***

## 플랫폼 보안 보장 (요약)

보안 취약점이나 서버 침해 등 CopyOdds **플랫폼 자체**의 보안 사고로 인해 사용자 자산이 직접적으로 손실된 경우, 플랫폼은 보안 보장 정책에 따라 보상을 제공합니다 (제품 페이지 및 법적 약관에 따름).

유의 사항:

- 플랫폼은 DM, 이메일 또는 고객 지원을 통해 시드 문구, 개인 키, 비밀번호 또는 인증 코드를 **절대** 요청하지 않습니다
- 예측 시장 거래 손실, 사용자 실수(잘못된 체인, 잘못된 주소), 피싱 사기 등은 "플랫폼 보안 사고 보상"의 대상이 아닙니다
- 항상 공식 도메인을 사용하세요

***

## 직접 해야 할 일

1. 공식 웹사이트 / 앱만 사용하세요: **copyodds.io**
2. **Authenticator를 활성화하세요** (출금에 필수. [2단계 인증 (2FA)](2fa.md) 참조)
3. 더 쉬운 로그인을 위해 선택적으로 Passkey를 추가하세요
4. [로그인한 기기](../account/devices-and-passkeys.md)를 정기적으로 검토하고 알아볼 수 없는 기기는 제거하세요
5. 페이지에 표시된 주소로 입금하고, **Verify deposit address**로 확인하세요
6. 첫 입금과 출금은 소액으로 테스트하세요

***

## 관련 페이지

- 입금 / 출금: `/wallets/deposit`, `/wallets/withdraw`
- 보안 설정: `/settings`
- 기기 관리: `/settings/devices`
- Passkey: `/settings/passkeys`

***

## 직접 확인하고 싶으신가요?

- 자금 이동 및 Gas 사용: **Transaction history** → `/wallets/ledger` ([거래 기록](../wallet/ledger.md) 참조)
- 로그인한 기기 및 출금 대기 시간: **Settings → Devices** → `/settings/devices` ([기기 및 Passkey](../account/devices-and-passkeys.md) 참조)
