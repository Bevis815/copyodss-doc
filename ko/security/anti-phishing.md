# 피싱 방지

흔한 피싱 수법으로는 인증 코드를 훔치거나 잘못된 주소로 자금을 보내도록 속이기 위한 가짜 웹사이트, 가짜 고객 지원 상담원, 가짜 에어드롭 등이 있습니다. 다음 사항을 기억하세요.

***

## 이것만 신뢰하세요

| 항목 | 올바른 예시 |
|------|-----------------|
| 웹사이트 / 앱 도메인 | **copyodds.io** / **app.copyodds.io** |
| 시스템 이메일 | **noreply@copyodds.io** (실제 공식 도메인 기준) |
| 입금 주소 출처 | 로그인 후 입금 페이지에 표시된 주소만 복사 |
| 주소 확인 | 앱에서 **Verify deposit address**를 사용하고, 공식 Telegram 봇 또는 연동된 이메일에서 확인 |

Smart money 같은 페이지 상단에도 같은 정보를 담은 스크롤 보안 배너가 표시될 수 있습니다.

![입금 주소 확인](../.gitbook/assets/verify_deposit_doc.png)

***

## CopyOdds는 절대 하지 않습니다

- **시드 문구 / 개인 키** 요청
- "고객 지원"으로 인증 코드를 보내라는 요청
- "출금 동결 해제"를 위해 알 수 없는 APK / 브라우저 확장 프로그램 설치 요구
- 비공식 도메인에서 모든 자산을 넘기는 서명을 요구하는 "지갑 업그레이드" 링크 발송

***

## 입금 안전 점검 목록

1. 공식 웹사이트를 직접 여세요. 요청하지 않은 DM의 링크를 클릭하지 마세요
2. 브라우저 주소창에서 도메인을 확인하세요
3. 주소를 복사하기 전에 올바른 네트워크를 선택하세요
4. **Verify deposit address**로 다시 확인하세요
5. 소액으로 시작하고, 도착한 후 더 입금하세요

***

## 출금 안전 점검 목록

1. 받는 주소는 본인의 지갑 / 거래소 출금 주소록에서 가져옵니다
2. 네트워크는 반드시 Polygon USDC여야 합니다
3. 추가 인증은 공식 앱 대화상자에서만 완료합니다
4. "지금 당장 어떤 주소로 출금하라"고 재촉하는 사람 → 의심하세요

***

## 의심스러운 점을 발견했다면

- 즉시 중단하고 더 이상 인증 코드를 입력하지 마세요
- 설정에서 기기와 Passkey를 확인하세요
- 필요하다면 이메일을 보호하고 (이메일 제공업체를 통해) 공식 고객 지원에 문의하세요
- 조사를 위해 피싱 링크와 채팅 기록의 스크린샷을 보관하세요
