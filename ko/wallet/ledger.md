# 거래 기록

**Transaction history** (거래 기록)는 계정의 모든 자금 입출금과 Gas 사용 내역을 기록합니다 — 은행 거래 명세서라고 생각하면 됩니다.

진입점: **Transaction history** → `/wallets/ledger` (보통 입금 / 출금 페이지에서 접근 가능)

***

## 표 항목

| 항목 | 의미 |
|-------|---------|
| **Network / Asset** | 예: Polygon (PoS) + USDC, BSC + USDT, Platform + Gas |
| **Type (In / Out)** | 입금 또는 출금 |
| **Status** | Received, Completed, Posted |
| **Balance after** | 이 항목 이후 계정에 남은 금액 |
| **View on-chain** | 블록 탐색기에서 이 트랜잭션 열기 |

세 종류의 기록:

| 유형 | 설명 |
|------|-------------|
| **입금** | 외부 지갑에서 이체된 USDC / USDT |
| **출금** | 본인의 주소로 전송됨 |
| **Gas 사용** | 카피 체결마다 차감되는 서비스 수수료 크레딧 |

***

## 숫자가 맞지 않을 때

| 증상 | 확인할 사항 |
|---------|---------------|
| 입금이 표시되지 않음 | 네트워크가 올바른지, 자산이 USDC/USDT인지, 주소가 해당 네트워크의 페이지 주소와 정확히 일치하는지, 온체인에서 확정되었는지 (BSC는 더 느림)? |
| 출금이 "Processing" 상태에서 멈춤 | 먼저 출금 추가 인증을 완료해야 함. 새 기기 사용이나 위험 관련 변경 후에는 대기 시간이 있을 수 있음 |
| Gas가 예상보다 많이 차감됨 | 모든 매수와 매도에 체결 금액의 약 0.5%가 부과됨. [플랫폼 Gas](gas.md)의 예시와 비교해 보세요 |
| 잔액이 포지션과 맞지 않음 | 포지션과 미체결 주문이 자금을 묶어 둠. **Max withdrawable**을 기준으로 하세요 |

찾을 수 없다면 원장의 **시각, 금액, 상태**를 온체인 해시와 함께 고객 지원에 보내 주세요.
