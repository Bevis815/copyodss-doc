# 거래 계정 및 지갑 페이지 상태

CopyOdds **거래 계정은 보통 로그인 후 자동으로 개설되며**, 별도의 신청이 필요 없습니다. 이것은 **수탁형 거래 지갑**으로, 입금한 USDC / USDT가 여기에 보관되어 카피 트레이딩에 사용됩니다.

진입점: **Wallets** → `/wallets` (**Deposit** 메뉴 항목을 누르면 이 페이지가 열립니다)

***

## 평소에 보게 되는 화면

| 섹션 | 내용 |
|---------|---------|
| 온체인 입금 주소 | 내 입금 주소 (**네트워크마다 다름**). 복사하거나 QR 코드를 저장 |
| 사용 가능 잔액 | 바로 카피에 사용할 수 있는 부분 |
| 온체인 잔액 | 블록체인에 실제로 도착한 네이티브 USDC |
| 플랫폼 Gas | 카피 트레이딩 서비스 수수료 결제에 사용 |
| 출금 | Polygon 수신 주소와 금액 입력 |
| 거래 기록 | 입금, 출금, Gas 사용 내역 |

이 모든 것이 보인다면 정상적으로 작동하고 있으며 바로 입금할 수 있습니다.

***

## 두 잔액이 다른 이유

| 용어 | 의미 |
|------|---------|
| **온체인 잔액** | 블록체인에 실제로 도착한 네이티브 USDC |
| **거래 가능 잔액** | 플랫폼이 처리를 완료하여 카피에 사용할 수 있는 부분 |

입금 직후 "온체인에 네이티브 USDC xx 있음, 거래 가능 잔액으로 자동 전환 중"이라고 표시된다면 **정상적인 흐름**입니다. 몇 분 기다린 후 새로고침하세요.

***

## 가끔 보일 수 있는 상태

모든 사용자에게 표시되는 것은 아닙니다. 표시된다면 아래 설명대로 처리하세요.

### "CopyOdds 거래 계정이 아직 개설되지 않음"

드물게 계정이 자동으로 개설되지 않는 경우가 있습니다 (예: 설정 중 문제가 발생한 경우). **Open trading account** (거래 계정 개설)를 탭하고, 약관을 읽고 체크한 후 확인하세요.

약관 요약:

| 조항 | 내용 |
|--------|---------|
| 서비스 | 플랫폼이 입금, 카피, 주문, 출금에 사용되는 수탁형 거래 지갑을 생성함 |
| 수탁 및 권한 부여 | 자산은 플랫폼이 보관하며 사용자는 개인 키를 직접 보유하지 않음. 사용자는 플랫폼이 필요한 서명과 거래 실행을 수행하도록 권한을 부여함 |
| 출금 보호 | 출금 전에 **Authenticator (TOTP)** 추가 인증을 활성화해야 할 수 있음 |
| 자금 및 네트워크 | 페이지에 표시된 주소와 네트워크로 지원되는 자산만 보낼 것. **잘못된 네트워크나 자산을 선택하면 자금을 복구하지 못할 수 있음** |
| 위험 고지 | 카피 트레이딩은 **고위험이며 투자금 전액을 잃을 수 있음**. 슬리피지, 유동성, 지연 모두 결과에 영향을 줌 |
| 자격 및 규정 준수 | 만 18세 이상이어야 하며, 자금 세탁, 사기 또는 기타 불법적인 목적으로 사용할 수 없음 |

> 약관은 업데이트될 수 있습니다. 전체 약관은 앱 내 대화상자와 사용자 서비스 약관에 있습니다.

### "Agent 권한 부여" 섹션이 나타남

일부 계정에서는 지갑 페이지에 **Agent authorization** (Agent 권한 부여) 섹션이 추가로 표시됩니다. 이를 통해 **한 번의 서명으로 권한을 부여**할 수 있으며, 이후 플랫폼이 대신 주문을 넣고 **온체인 가스비를 부담합니다** (본인의 MATIC이 필요 없음).

이 섹션이 보인다면 안내에 따르기만 하면 됩니다:

| 요구 사항 | 설명 |
|-------------|-------------|
| **가입할 때 사용한 지갑**으로 서명 | 지갑에서 잘못된 계정을 선택하면 "현재 지갑이 등록된 지갑이 아닙니다"라고 표시됨 |
| 지갑을 **Polygon (체인 ID 137)** 네트워크로 전환 | 그렇지 않으면 "지갑을 Polygon으로 전환한 후 다시 시도하세요"라고 표시됨 |
| 한 번에 서명 완료 | 도중에 확장 프로그램을 닫거나 내용을 변경하면 실패함. 새로고침하고 처음부터 다시 시작 |
| 만료 확인 | 만료되면 카피가 일시 중지됨 — **Renew** (갱신)를 탭하세요. **Revoke** (철회)할 수도 있음 (철회 후에는 다시 권한을 부여해야 함) |

흔한 오류: 잘못된 지갑 / 잘못된 체인 / 권한 부여 요청 만료 / 서명 내용이 검증과 일치하지 않음 (보통 확장 프로그램 간섭 — 새로고침하고 다시 시도).

### "Polymarket 거래 권한 부여 미완료"

**Re-authorize Polymarket**을 탭하세요. 이 메시지는 권한 부여 단계의 문제를 나타내며 **이미 입금한 자금에는 영향을 주지 않습니다**.

> 드물게 자동 권한 부여가 실패하는 경우, 페이지에 문제 해결을 위한 "Polymarket API 자격 증명 수동 붙여넣기 (고급)" 옵션이 제공됩니다. 일반 사용자는 건드릴 필요가 없습니다.

## 자주 묻는 질문

**거래 계정에 수수료가 있나요?**  
개설은 무료입니다. 카피 거래가 체결될 때만 약 0.5%의 플랫폼 Gas가 차감됩니다.

**제 개인 키는 어디에 있나요?**  
사용자에게 있지 않습니다. CopyOdds는 플랫폼이 개인 키를 격리하여 보관하는 수탁형 지갑을 사용하며, 사용자는 로그인 + 출금 추가 인증을 통해 자금을 통제합니다.

**온체인 주소는 보이는데 왜 직접 자금을 옮길 수 없나요?**  
그것이 수탁형 설계입니다. 주소는 플랫폼에 속하며 입금을 받는 데 사용됩니다. 자금을 옮기려면 **출금** 절차를 거쳐 추가 인증을 완료해야 합니다.

**두 잔액은 언제 다른가요?**  
보통 **입금 직후 자동 전환이 진행되는** 몇 분 동안만 다릅니다. 오랫동안 계속 다르면 새로고침하고, 그래도 맞지 않으면 트랜잭션 해시와 함께 고객 지원에 문의하세요.
