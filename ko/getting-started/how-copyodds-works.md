# CopyOdds 작동 방식

"트레이더의 체결"부터 "내 계정의 카피 시도"까지 전체 흐름은 다음과 같습니다:

```text
스마트 머니 트레이더가 Polymarket에서 체결됨
        ↓
CopyOdds가 공개 체결을 감지
        ↓
해당 주소에 대한 내 카피 규칙과 매칭
        ↓
규칙에 따라 주문 규모 계산 (고정 금액 또는 잔액의 %)
        ↓
슬리피지 범위 내에서 주문 시도 (플랫폼 Gas 소모)
        ↓
결과는 Trade history에 기록되고, 보유 자산은 Positions에 표시됨
```

## 1. 트레이더 발굴

- 시스템은 Polymarket의 공개 지갑을 지속적으로 점수화하고 선별합니다
- **표시되는 리더보드**는 보통 종합 점수가 기준치(예: ≥ 40)를 충족해야 하며, 점수가 낮은 주소는 목록에서 빠질 수 있습니다
- **Smart money**에서는 목록에 없는 주소를 둘러보거나 검색하거나 분석할 수 있습니다 (이 기능을 사용할 수 있는 경우 일일 한도가 적용될 수 있습니다)

## 2. 자금과 수수료는 별개입니다

| 계정 내 자원 | 용도 |
|---------------------|---------|
| **USDC (등)** | 카피 원금: 매수 시 사용되고 매도 시 돌아옴 |
| **플랫폼 Gas** | 서비스 수수료 크레딧: 카피 체결 1건마다 체결 금액의 약 0.5%가 차감됨 |

Gas가 0이면 **카피 규칙을 생성 / 재개할 수 없습니다**. 기존 규칙은 보통 계속 실행되지만 **매수는 건너뛰어지며**, 포지션을 보유하고 있다면 매도는 여전히 카피될 수 있습니다.

## 3. 카피 규칙의 적용 방식

리더 주소마다 하나의 규칙을 저장합니다 (같은 주소에 다시 저장하면 덮어씁니다):

- **카피 모드** (하나 선택, 기본값 **Ratio**):
  - **Ratio**: 리더의 체결 금액 × 내 비율 = 내 주문 금액
  - **By balance %**: 각 거래에 내 사용 가능 USDC의 일정 비율을 사용
  - **Fixed amount**: 모든 거래에서 같은 금액을 매수
  - [세 가지 카피 모드](../copy-trading/copy-modes.md)를 참조하세요
- **방향**: Both / Buy only / Sell only (양방향 / 매수만 / 매도만)
- **슬리피지**: 가격이 너무 많이 움직이면 체결하지 않음 (기본값 15%)
- **카피 비율 / 규모 범위** (Ratio 모드 전용): "얼마나 카피할지"와 "어떤 주문 규모를 카피할지"를 제어
- **Max open copy buys** (최대 미결 카피 매수): 기본값 1 (포지션 추가 없음). 늘릴 수 있으며, 최대값은 **All (무제한)**

리더의 체결을 감지하면 시스템은 이 규칙을 사용해 주문을 시도합니다. 모든 거래가 카피된다고 **보장하지는 않습니다**.

## 4. 거래가 카피되었는지 확인하는 방법

| 확인할 곳 | 알 수 있는 내용 |
|---------------|-------------------|
| Copy activity | 트레이더가 한 일 |
| Trade history | 내 카피 시도 결과 (체결 / 건너뜀 / 실패) |
| Positions | 현재 보유 중인 것 |
| My copies | 규칙 상태: Following / Manually paused / Funding alert (팔로우 중 / 수동 일시 중지 / 자금 알림) |

## 5. 입금과 출금 네트워크는 다릅니다 (중요)

- **입금**: Polygon (PoS) 및 BSC (활성화된 경우), 자산은 USDC / USDT
- **출금**: **Polygon (PoS) USDC**만 가능
- 두 입금 네트워크는 **서로 다른 주소**를 사용하므로 절대 혼동하지 마세요

[지원 네트워크](../wallet/supported-networks.md)를 참조하세요.

## 6. 보안 모델 요약

CopyOdds는 **수탁형 거래 계정**을 사용합니다. 사용자마다 하나의 지갑이 있으며 개인 키는 격리되어 있습니다. 출금에는 **Authenticator (TOTP)** 추가 인증이 필요합니다. [보안](../security/wallet-security.md)을 참조하세요.
