# 빠른 시작

다음 단계를 따라 앱을 여는 것부터 첫 카피 규칙을 만드는 것까지 진행하세요. 항상 공식 도메인 **copyodds.io / app.copyodds.io**만 사용하세요.

![로그인 페이지](../.gitbook/assets/login_doc.png)

***

## 1. 로그인 또는 계정 만들기

1. 앱을 열고 **Login** (로그인)으로 이동합니다.
2. 이메일 입력 → **Send code** (코드 보내기) → 6자리 코드 입력 → 로그인합니다.
3. **새 이메일은 자동으로 계정이 생성됩니다** (이름을 입력하는 별도의 회원가입 페이지는 없습니다. 화면에서 이름 / 약관 동의를 계속 요청하면 안내에 따르기만 하면 됩니다).
4. 선택 사항: **Passkey** 또는 **Telegram**으로 로그인할 수 있습니다.
5. 초대 링크를 통해 들어온 경우 초대 코드는 보통 자동으로 입력됩니다.

### 참고

- 인증 코드는 보통 약 5분간 유효하며, 보낸 직후에는 다시 보낼 수 없습니다
- 이메일이 도착하지 않으면 스팸 / 프로모션 폴더를 확인하세요
- Passkey는 지원되는 기기와 브라우저에서 등록해야 합니다 (설정에서 관리)

***

## 2. USDC / USDT 입금

1. **Assets / Deposit** (자산 / 입금) 열기 → `/wallets/deposit`
2. **네트워크 선택**: Polygon (PoS) 또는 BSC (거래소에서 출금하는 네트워크와 일치해야 함)
3. **자산 선택**: USDC 또는 USDT만 가능
4. 이 페이지의 주소를 복사하거나 QR 코드를 스캔하여 전송합니다 (**Polygon과 BSC 주소는 서로 다르므로 절대 혼동하지 마세요**)
5. 온체인 확정을 기다립니다. BSC는 몇 분 더 걸릴 수 있습니다

![입금 페이지](../.gitbook/assets/usdc1_doc.png)

자세한 내용은 [입금](../wallet/deposit.md) 및 [지원 네트워크](../wallet/supported-networks.md)를 참조하세요.

***

## 3. 플랫폼 Gas 구매

1. **Gas Store** 열기 → `/store`
2. 현재 Gas 및 USDC 잔액 확인
3. 패키지 선택 → 수탁형 지갑의 USDC로 결제
4. Gas는 즉시 충전됩니다 (출금 불가)

![Gas Store](../.gitbook/assets/store_doc.png)

수수료 요약: 카피 체결 1건마다 체결 금액의 약 **0.5%** 만큼 Gas가 차감되며, **1 USDC ≈ 100 Gas**입니다. [플랫폼 Gas](../wallet/gas.md)를 참조하세요.

***

## 4. 트레이더 선택 및 카피

1. 홈 페이지 **Leaderboard** 또는 **Smart money** 열기 → `/` 또는 `/smart-money`
2. 카테고리, 빠른 필터 또는 고급 필터를 사용해 트레이더를 선택합니다
3. **Follow** (팔로우)를 탭하거나, 먼저 프로필을 열고 거기서 팔로우합니다
4. **카피 모드** (기본값 **Ratio**), 슬리피지 및 고급 옵션을 선택합니다
5. Gas > 0인지 확인한 후 저장 → **My copies** (내 카피)에서 관리합니다

![Smart money + Follow](../.gitbook/assets/smarket_doc.png)

![카피 설정](../.gitbook/assets/follow_doc.png)

***

## 5. 카피가 작동하는지 확인

| 페이지 | 용도 |
|------|---------|
| **My copies** | 규칙이 활성화되어 있는지, 자금 알림이 있는지 |
| **Trade history** | 내 주문이 체결 / 건너뜀 / 실패했는지 |
| **Copy activity** | 트레이더의 공개 활동 (내 체결이 **아님**) |
| **Positions** | 현재 포지션. 여기서 청산 / 상환 |

***

## 초보자를 위한 팁

- 소액을 입금하고 Gas를 조금 구매한 후, 1–2일 동안 소액 고정 금액으로 테스트해 보세요
- 자금이나 Gas가 부족하면 매수는 건너뛰어지지만 규칙은 보통 자동으로 일시 중지되지 **않습니다**. 충전 후 **My copies**로 이동하여 **Resume buys** (매수 재개)를 탭하세요
- 출금은 **Polygon USDC**만 지원합니다. 제출하기 전에 주소를 다시 확인하세요

***

## 누구를 카피할지 모르겠다면? 안전한 두 가지 방법

1. **먼저 Leaderboard를 확인하세요** (홈 페이지). 최근 실적이 꾸준한 계정을 찾은 다음, 프로필 페이지에서 점수와 낙폭을 확인하세요
2. **그래도 확신이 서지 않으면 먼저 [시뮬레이션 카피 트레이딩](../copy-trading/simulation.md)을 해 보세요** — 실제 자금이 들지 않습니다

확신이 생기면 이 페이지의 4단계로 돌아와 실제 카피를 시작하세요.
