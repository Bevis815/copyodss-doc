# 모바일에서 CopyOdds 사용하기 (Mobile App)

아무것도 다운로드하지 않고도 CopyOdds를 사용할 수 있습니다. 가장 적합한 방법을 선택하세요.

진입점: **Mobile App** → `/mobile-app`

***

## 네 가지 사용 방법

| 방법 | 설명 | 적합한 사용자 |
|--------|-------------|----------|
| **웹** | 브라우저에서 바로 열기, 설치 불필요 | 데스크톱 사용자, 가끔 사용하는 분 |
| **홈 화면에 추가 (PWA)** | 브라우저의 "홈 화면에 추가"로 전체 화면 환경과 푸시 알림 사용 | 대부분의 모바일 사용자 (권장) |
| **Telegram 미니 앱** | Telegram 안에서 바로 열기 | Telegram을 주로 사용하는 분 |
| **Android 앱** | Google Play에서 다운로드 | 보다 네이티브한 경험을 원하는 분 |

지원 기기: iPhone / iPad (Safari), Android (Chrome), Windows 및 Mac (Chrome / Edge).

***

## 권장: 홈 화면에 추가 (PWA)

CopyOdds는 PWA (Progressive Web App)이므로 **앱 스토어가 필요 없습니다**. 홈 화면에 추가하면:

- 브라우저 주소창 없이 **전체 화면**으로 사용
- **홈 화면 아이콘에서 한 번의 탭으로 실행**
- **푸시 알림**으로 앱이 닫혀 있어도 카피 알림을 받음

### 설치 방법

- **iPhone / iPad**: Safari에서 웹사이트 열기 → 공유 → **홈 화면에 추가**
- **Android**: Chrome에서 웹사이트 열기 → 메뉴 → **앱 설치 / 홈 화면에 추가**

"설치됨"이라고 표시되면 이전에 이미 추가한 것이므로 홈 화면 아이콘에서 열기만 하면 됩니다.

***

## Android 앱

**Mobile App** 또는 **Settings → Version** 페이지에서 다음을 확인할 수 있습니다:

- 현재 앱 버전
- 새 버전 사용 가능 여부 (**Update Available** / **Up to date**)
- Google Play 링크 및 해당 버전의 릴리스 노트

***

## 모바일에서 인터페이스가 다른 점

| 위치 | 내용 |
|----------|---------|
| 하단 탭 바 | Leaderboard / Smart money / My copies / Deposit |
| 왼쪽 상단 메뉴 | 나머지 모든 항목 (Copy activity, Positions, Executions, Gas Store, Affiliation, Settings 등) |
| 당겨서 새로고침 | 대부분의 목록 페이지는 아래로 당기면 새로고침됨 |
| Telegram 안에서 열었을 때 | Telegram의 뒤로 가기 버튼 동작에 자동으로 맞춰짐 |

***

## 자주 묻는 질문

**앱을 꼭 다운로드해야 하나요?**  
아니요. 웹 버전에서 모든 기능을 사용할 수 있습니다.

**설치 후 푸시 알림이 오지 않나요?**  
휴대폰 시스템 설정에서 해당 앱의 알림이 허용되어 있는지 확인하세요. iOS에서는 시스템 설정에서 해당 앱의 알림 권한을 켜세요.

**휴대폰을 바꾸셨나요?**  
새 기기에서 다시 로그인한 후(이메일 인증 코드 / Telegram / Passkey), [기기 관리](../account/devices-and-passkeys.md)에서 이전 기기를 제거하세요.
