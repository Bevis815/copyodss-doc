# 앱 둘러보기

앱을 처음 열면 어디를 눌러야 할지 알기 어려울 수 있습니다. 이 페이지에서는 모든 진입점을 쉬운 말로 설명하여 길을 찾을 수 있도록 도와드립니다.

> 팁: 모바일에서는 하단 바에 자주 쓰는 4개의 탭(**Leaderboard / Smart money / My copies / Deposit**)이 있고, 나머지는 모두 왼쪽 상단 메뉴에 있습니다. 데스크톱에서는 모두 왼쪽 사이드바에 있습니다.

***

## 1. 주요 기능 (왼쪽 사이드바 상단)

| 메뉴 | 무엇인가요 | 언제 사용하나요 |
|------|------------|----------------|
| **Leaderboard** | 카피 풀 순위 | 플랫폼 카피 풀에서 오늘 누가 가장 많이 벌었는지 보고, 거기서 트레이더를 고를 때 |
| **Smart money** | 트레이더 선별기 | 점수, 낙폭 등의 기준으로 트레이더를 필터링할 때 |
| **My copy trading** | 내 카피 규칙 | 켜 둔 카피 규칙을 관리할 때 (일시 중지, 재개, 설정 변경) |
| **Simulation copy trading** | 연습 모드 | 실제 자금 없이 먼저 카피 트레이딩을 해 볼 때 |
| **Store** | Gas Store | 플랫폼 Gas (서비스 수수료 크레딧)를 구매할 때 |
| **My positions** | 내 보유 자산 | 어떤 마켓을 보유 중인지, 원가, 수익 / 손실 여부를 볼 때 |
| **Executions** | 거래 내역 | 각 카피 시도의 결과 (체결 / 건너뜀 / 실패)를 볼 때 |
| **Affiliation** | 제휴 프로그램 | 친구를 초대하고 커미션을 받을 때 |

***

## 2. 자금 및 설정 (왼쪽 사이드바 하단)

| 메뉴 | 무엇인가요 | 언제 사용하나요 |
|------|------------|----------------|
| **Deposit** | 입금 | 온체인 USDC / USDT를 플랫폼으로 옮길 때 |
| **Profile** | 내 개요 | Gas 잔액과 지갑 잔액을 한눈에 보고, 제휴 페이지로 바로 이동할 때 |
| **Withdraw** | 출금 | USDC를 내 지갑 주소로 돌려보낼 때 |
| **Settings** | 설정 | 언어, 알림, 계정 연동, 보안 상태, 앱 버전 |
| **Mobile App** | 모바일 다운로드 | 홈 화면에 추가 / 앱 다운로드 |
| **User guide** | 이 문서 | 지금 읽고 계신 문서 |

***

## 3. 헷갈리기 쉬운 페이지

| 페이지 | 한 문장 요약 |
|------|-----------------|
| **Leaderboard** | **카피 풀 계정**의 일일 수익 순위 |
| **Smart money** | **개별 트레이더 주소**의 점수, 승률, 낙폭 등 프로필 데이터 |
| **My positions** | **내가 현재 보유한** 것 |
| **Executions** | **시스템이 나를 대신해 넣은 모든 주문**의 결과 |
| **Copy activity** | **트레이더**가 방금 한 일과 내가 그것을 카피했는지 여부 |
| **Transaction history** | **자금 입출금** (입금, 출금, Gas 사용) |
| **Profile** | **내 자산 개요**와 제휴 진입점 |

***

## 4. 권장 사용 순서

1. **로그인**
2. **입금**
3. **Gas 구매**
4. **트레이더 선택 (Leaderboard / Smart money)**
5. **Follow를 탭하여 카피** (기본값: **Ratio** 모드)
6. **My copies**로 돌아가 상태가 **Following** (팔로우 중)인지 확인
