# 리더보드 (카피 풀 일일 수익)

**Leaderboard** (리더보드)는 앱의 홈 페이지(`/`)입니다. 플랫폼 카피 풀에 있는 계정을 **일일 수익** 기준으로 순위를 매기며, 말하자면 "최근 누가 카피를 잘하고 있는지 보여 주는 성적표"입니다.

페이지에는 **보드 날짜 (영업일)** 정보가 표시되며, 영업일의 시작 시각은 페이지에 표시된 대로입니다.

***

## 페이지 구성

| 요소 | 의미 |
|---------|---------|
| **Board · date** | 이 보드가 다루는 날짜 |
| **Daily PnL** | 해당 영업일에 계정이 번 금액 |
| **7D** | 최근 7일간의 손익 |
| **Current leader / Rank** | 보드에서의 순위 |
| **View analysis / View account** | 계정 상세 정보로 이동 |
| **Top N / All N** | 상위 몇 개만 보기 또는 전체 보드 펼치기 |

***

## 사용 방법

1. 앱을 엽니다 — 기본적으로 Leaderboard에 도착합니다
2. 먼저 **Daily PnL + 7D**를 확인하세요. 하루 수익이 났다고 꾸준하다는 뜻은 아닙니다
3. **View analysis** 또는 **View account**를 탭하여 이 계정이 누구를 카피하고 있는지 확인합니다
4. 만족스러우면 보드에서 바로 **Follow** (팔로우)를 탭하여 카피 설정 대화상자를 엽니다

> 보드에 있는 계정들도 카피하는 사용자입니다. 이들의 수익은 "이런 유형의 트레이더를 카피하면 때때로 효과가 있다"는 것을 보여 줄 뿐, 내가 카피하면 같은 수익을 얻는다는 뜻이 아닙니다.
