# 트레이더 지표 이해하기

리더보드와 프로필 페이지의 숫자는 항상 같은 방식으로 계산되지는 않습니다. 아래는 가장 자주 보게 될 항목입니다. **모든 지표는 참고용이며 미래 실적을 보장하지 않습니다.**

***

## 종합 점수와 등급

| 개념 | 설명 |
|---------|-------------|
| **종합 점수 / 트레이더 점수** | 다중 요인 모델의 결과. 높을수록 보통 전반적인 성과가 좋음 |
| **리더보드 순위** | 기본 전체 순위는 여러 순위를 조합할 수 있으며, 단순히 종합 점수순으로 정렬된 것이 **아님** |
| **등급 (S–D)** | 주소의 품질 등급 라벨 (예: S = 최상위 스마트 머니 → D = 주의 / 고위험) |
| **위험** | Low / Medium / High 등의 위험 수준 안내 |

### 점수 요인 (일반적인 항목)

| 요인 | 의미 (간략) |
|--------|----------------------|
| 우위 | 예측 / 가격 책정의 우위 |
| 수익성 | 돈을 버는 능력 |
| 카피 적합도 | 지연 및 슬리피지 가정에서 따라가기 쉬운지 |
| 낙폭 건전성 | 낙폭이 통제되고 있는지 |
| 일관성 | 성과가 지속적이고 안정적인지 |
| 스타일 감점 | 도박성 집중 등의 특성은 점수를 낮출 수 있음 |

점수 산정 기간은 대부분 최근 표본이며, 계정 생성 이후의 전체 기록이 아닙니다.

***

## 목록 / 카드의 일반적인 지표

| 지표 | 해석 방법 |
|--------|----------------|
| **총 손익** | 명시된 방법론에 따른 손익. 최근 기간인지 공식 PnL 서비스인지 확인하세요 |
| **7일 손익** | 단기 성과. 변동이 클 때는 의미가 적음 |
| **승률** | 종료된 표본 중 맞힌 비율. 높은 승률 ≠ 수익 보장 |
| **낙폭 / DD** | 최고점 대비 하락폭. 보통 낮을수록 좋음 |
| **Copy fit** | 시뮬레이션 카피 적합도: High / Medium / Low |
| **수익 팩터** | 총 이익 대비 총 손실의 비율형 지표 |
| **안정성 / 활동성** | 수익 변동성 및 거래 빈도와 관련 |
| **7일 거래 수 / 거래량** | 아직 활발히 거래하고 있는지 |
| **평균 종료 수익률** | 종료된 표본 전체의 평균 수익률형 지표 |

"시뮬레이션"으로 표시된 열(백테스트 손익, 카피 손실, 슬리피지 등)은 **지연 체결을 가정한** 시뮬레이션이며, 플랫폼 사용자의 실제 카피 결과가 **아닙니다**.

***

## 프로필 스냅샷 (일반적인 항목)

| 항목 | 설명 |
|-------|-------------|
| 현재 자금 | 트레이더 자금 규모의 참고치 |
| 총 손익 / 미실현 손익 | 실현 손익 및 미결 포지션의 평가 손익 |
| 총 거래량 | 거래 활동의 참고치 |
| 총 수익률 / 평균 이익률 | 수익률형 비율 |
| 승 / 패 | 표본 구성 |
| 수익 팩터 | 수익의 질 |
| 최대 수익 / 최대 손실 (낙폭) | 꼬리 위험 |
| 최근 활동 | 아직 거래하고 있는지 |

***

## "실제 카피 성과" vs. "카피 시뮬레이션"

| 유형 | 의미 |
|------|---------|
| **카피 시뮬레이션** | 지연 + 슬리피지를 가정하여 "카피했다면 어떻게 되었을지"를 시스템이 백테스트한 결과 |
| **실제 카피 성과** | 플랫폼에서 이 주소를 실제로 카피하는 사용자의 표본 (ROI, 카피 손익, 구독자 수 등). 표본이 부족하면 숨겨질 수 있음 |

**둘 다** 카피 후 내 결과를 보장하지 않습니다.

***

## 해석 팁

1. 총 손익보다 점수, 낙폭, 카피 적합도를 먼저 보세요
2. 표본이 너무 적으면 승률과 ROI가 쉽게 왜곡됩니다
3. 마켓 메이커 / 극단적으로 집중 베팅하는 주소는 지표가 좋아 보여도 카피에 적합하다는 뜻이 아닙니다
4. 결국 카피 결과는 내 **Trade history**로 판단하세요
