# 트레이더 선택 방법

"반드시 이기는 사람"은 없습니다. 선택할 때는 "과거에 얼마나 벌었는지"보다 **카피 적합도, 위험, 활동성, 자금 규모**를 우선하세요.

***

## 권장 선택 절차

### 1. 먼저 나만의 제약 조건 정하기

- 카피 거래 1건당 최대 금액 (또는 잔액의 %)
- 감당할 수 있는 최대 낙폭과 연속 손실
- 선호하는 마켓 유형 (정치 / 스포츠 / 암호화폐 등)

### 2. 필터로 후보군 좁히기

- 초보자는 **Featured**, **High copyability**, **Steady**, **Low drawdown**부터 시작할 수 있습니다
- 위험을 충분히 이해하지 않는 한, 카피에 명백히 적합하지 않은 스타일(예: 대량 마켓 메이킹 / 극단적인 도박 패턴)은 피하세요
- 거래 수가 매우 적은 주소는 승률과 수익률의 가치가 제한적입니다

### 3. 프로필 페이지에서 교차 확인하기

프로필 페이지에서는 다음에 집중하세요:

| 확인할 항목 | 이유 |
|---------------|-----|
| 트레이더 점수 + 요인 | 전반적으로 카피하기에 적합한지 |
| 낙폭 / 위험 메모 | "크게 벌고 크게 잃는" 유형인지 |
| 최근 7일 활동 및 손익 | 아직 거래하고 있는지 |
| 카피 시뮬레이션 | 지연 상황에서 따라가기 쉬운지 (시뮬레이션 ≠ 현실) |
| 실제 카피 성과 | 표본이 충분할 때 더 의미 있음. 적은 표본을 과대 해석하지 마세요 |

### 4. 소액으로 테스트하기

1. 소액 고정 금액이나 낮은 비율로 규칙을 만듭니다
2. 1–3일 동안 **Trade history**에서 체결 / 건너뜀 / 실패 사유를 지켜봅니다
3. 그런 다음 금액을 늘릴지 트레이더를 바꿀지 결정합니다

***

## 흔한 실수

| 실수 | 더 안전한 방법 |
|---------|----------------|
| 총 손익이 가장 높은 것만 보기 | 낙폭, 표본 크기, 카피 적합도도 확인하기 |
| 시뮬레이션 ROI를 내가 벌 돈으로 여기기 | 시뮬레이션은 지연/슬리피지를 가정함. 내 거래 내역을 기준으로 하기 |
| 승률이 100%에 가까운 사람은 누구든 팔로우하기 | 표본 크기, 미결 포지션, 낙폭이 앞뒤가 맞는지 확인하기 |
| 마켓 메이커의 "거래량" 주소 카피하기 | 일반적인 카피로는 그들의 체결 구조를 거의 재현할 수 없음 |
| 여러 트레이더를 한꺼번에 큰 금액으로 카피하기 | 소액으로 집중해서 시작하고, Gas / 자금 / 규칙이 모두 작동하는지 확인하기 |

***

## 트레이더를 바꾸거나 규모를 줄여야 할 때

- 최근 활동이 눈에 띄게 줄었을 때
- 낙폭이나 위험 메모가 나빠졌을 때
- 내 거래 내역에 슬리피지 실패 / 장기간 건너뜀이 많을 때
- 트레이더의 스타일이 내 자금 규모와 맞지 않을 때 (거래가 너무 크거나 너무 잘게 쪼개져 있음)

트레이더를 골랐다면 [트레이더 카피하는 방법](../copy-trading/how-to-follow.md)을 참조하세요.
