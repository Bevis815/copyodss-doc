# 스마트 머니 리더보드 (트레이더 프로필로 필터링)

스마트 머니 리더보드는 카피할 가치가 있는 Polymarket 트레이더를 찾는 데 도움을 줍니다. 진입점: **Smart money** → `/smart-money` (앱 홈 페이지는 이제 [카피 풀 일일 수익 보드](copy-pool-board.md)이므로 메뉴에서 Smart money를 여세요).

![스마트 머니 리더보드](../.gitbook/assets/smarket_doc.png)

***

## 여기서 할 수 있는 일

1. **리더보드 둘러보기** — 손익, 점수, 승률, 최근 7일 등을 카드 또는 표 형식으로 보기
2. **주소 검색** — 지갑 주소로 트레이더 찾기
3. **필터** — 카테고리, 빠른 프리셋, 고급 필터 (등급, 스타일, 지표 범위, 카피 적합도 등)
4. **순위 기간** — 전체 / 주간 / 월간 (기본값은 보통 전체 순위이며, 단순히 종합 점수순으로 정렬된 것은 아닙니다)
5. **카피** — **Follow** (팔로우)를 탭하여 카피 설정을 열거나, 먼저 프로필을 열고 거기서 결정하기

***

## 리더보드 데이터 계산 방식 (필독)

- 손익 곡선, 최근 7일 / 총 수익 등은 보통 Polymarket의 공식 PnL 데이터에서 가져옵니다
- 승률, 수익 팩터 등은 대부분 **종료된 마켓**을 기준으로 합니다
- 점수와 백테스트 지표는 **최근 기간의 체결** (약 30일 / 최대 약 4,000건)을 기준으로 하며, **전체 기간의 원장이 아닙니다**
- **표시되는 리더보드**는 보통 종합 점수가 기준치(예: ≥ 40)를 충족하는 주소만 포함하며, 반복적으로 점수가 낮은 주소는 목록에서 빠질 수 있습니다
- "Copy fit / 백테스트 손익 / 슬리피지" 등은 대부분 **지연 + 슬리피지를 가정한 시뮬레이션**이며, 플랫폼에서 카피하는 사용자의 실제 손익이 아닙니다

> 리더보드는 **투자 조언이 아닙니다**. 과거 실적이 미래 수익을 보장하지 않습니다.

## 자주 쓰는 필터

### 카테고리 예시

전체, 정치, 스포츠, e스포츠, 암호화폐, 문화, 날씨, 경제, 기술, 금융, 멘션 등.

### 빠른 필터 예시

| 프리셋 | 대략적인 용도 |
|--------|---------------|
| Featured | 플랫폼 추천 트레이더, 카피하기 쉬운 쪽에 가까움 |
| Steady | 비교적 보수적인 스타일 |
| High copyability | 시뮬레이션에서 따라가기 더 쉬움 |
| Recently active | 최근 기간에 거래가 더 잦음 |
| All copyable | 카피 가능한 주소 |
| High win rate / High return / Low drawdown | 해당 지표로 범위 좁히기 |
| Long-term stable | 일관성이 더 좋은 후보 |

### 고급 필터 (자주 쓰는 옵션)

- 카피 가능한 주소만 / 추천만 (마켓 메이커 제외)
- 등급 (S–D), 거래 스타일
- 지표 범위 (예: 최근 7일 거래 수, 승률)
- 특정 위험 태그 제외
- 카피 적합도: 높음 / 중간 / 낮음

***

## 거래 스타일 태그 (참고용)

| 태그 | 의미 (간략) |
|-----|----------------------|
| 정보 우위 | 일찍 포지션을 잡는 경향 / 정보 주도형 |
| 차익 거래 | 스프레드 / 차익 거래 패턴 |
| 도박형 | 변동성이 큰 베팅 패턴. 카피 시 각별히 주의 |
| 마켓 메이커 | 고빈도 마켓 메이킹. 보통 일반적인 카피에 적합하지 않음 |
| 혼합형 | 일반적인 혼합 스타일 |

***

## 제안

1. Featured / High copyability / Steady 같은 프리셋으로 먼저 범위를 좁히세요
2. 프로필을 열어 점수 요인, 낙폭, 위험 메모를 검토하세요
3. 소액으로 팔로우하여 테스트한 다음 점진적으로 조정하세요
4. 트레이더를 공유할 때는 프로필 링크 형식을 사용하세요: `https://app.copyodds.io/@0xADDRESS` (중국어 UI를 보려면 `/zh`를 추가하세요)
