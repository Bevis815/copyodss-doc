# 설정

진입점: **Settings** → `/settings`

설정 페이지에는 카피 트레이딩 외의 모든 스위치가 한곳에 모여 있습니다. 로그인하지 않은 상태라면 로그인 안내만 표시됩니다.

***

## 1. 일반

| 항목 | 설명 |
|------|-------------|
| **Language** (언어) | 인터페이스 언어 전환. 전환 후 URL에 언어 접두사가 붙음 (예: `/zh`) |
| **Name** (이름) | 고객 지원이 본인 확인을 할 수 있도록 이름과 성을 입력 |

***

## 2. 카피 트레이딩

- **수탁형 거래 주소**: 로그인 후 자동으로 개설되며, 실제 수신 / 거래 주소입니다
- "아직 개설되지 않음"으로 표시되면, 입금하기 전에 안내에 따라 이 페이지에서 개설하세요
- 처음 사용하는 경우: 큰 금액을 사용하기 전에 소액 입금 + 소액 출금으로 전체 흐름을 한 번 진행해 보세요

***

## 3. 알림

알림 유형별로 개별적으로 켜고 끌 수 있습니다:

| 분류 | 알림 |
|----------|--------|
| 거래 | 트레이더 주문 감지, 주문 제출, 주문 실패, 주문 체결, 주문 취소 |
| 예산 및 한도 | 예산 경고, 잔액 부족 |
| 시스템 | 자동 상환, 세션 만료 임박 |

> 환경설정은 저장하는 즉시 적용됩니다. 실시간 푸시 등 더 고급 채널은 단계적으로 제공되고 있으며, 페이지에 현재 상태가 표시됩니다.

***

## 4. 계정 연동

| 연동 | 용도 |
|------|---------|
| **Email** (이메일) | 로그인용 인증 코드 수신. 연동하면 이메일 또는 Telegram 중 하나로 로그인 가능 |
| **Telegram** | Telegram으로 로그인 |
| **Web3 wallet** (Web3 지갑) | 외부 지갑 정보 기록 |

> 연동하려는 이메일 / Telegram이 이미 다른 계정에 속해 있다면, 연동 시 **현재 계정이 유지되며** 다른 계정은 더 이상 그 방법으로 로그인할 수 없습니다.

***

## 5. 보안

계정 보안 상태 카드:

| 항목 | 설명 |
|------|-------------|
| **Active sessions** (활성 세션) | 현재 로그인 세션 수와 만료 시각 |
| **Devices** (기기) | 로그인한 기기 관리. [기기 및 Passkey](devices-and-passkeys.md) 참조 |
| **Terms status** (약관 상태) | 사용자 약관에 동의했는지 여부 |
| **Trading status** (거래 상태) | Normal / Restricted (정상 / 제한) |
| **Withdrawal verification** (출금 인증) | 출금 전에 필요한 추가 인증 방법에 대한 설명 |

### 출금 추가 인증

출금할 때마다 본인 확인을 해야 합니다. **현재는 Authenticator 코드만 지원됩니다**. 연동되어 있지 않다면 먼저 설정에서 활성화하세요. Passkey와 이메일 인증 코드는 출금에 사용할 수 없습니다.

***

## 6. 정보

| 항목 | 내용 |
|-------|---------|
| **User Agreement** (사용자 약관) | `/settings/terms` |
| **Privacy Policy** (개인정보 처리방침) | `/settings/privacy` |
| **Version** (버전) | `/settings/version` — 현재 버전, 새 버전 사용 가능 여부, Android 다운로드 확인 |

***

## 7. 로그아웃

설정 페이지 하단에서 로그아웃할 수 있습니다. 로그아웃한 후에는 카피 트레이딩, 지갑 및 기타 기능을 사용하려면 다시 로그인해야 하며, 규칙 자체는 삭제되지 않습니다.
