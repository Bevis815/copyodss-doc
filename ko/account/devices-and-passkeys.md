# 기기 및 Passkey

이 페이지에서는 두 가지 보안 주제를 다룹니다: **어떤 기기가 내 계정에 로그인했는지**, 그리고 **Face ID / 지문으로 빠르게 로그인하는 방법**.

진입점: 설정 → 보안 → **Devices** → `/settings/devices`. Passkey는 설정 → `/settings/passkeys`에서 관리합니다

***

## 1. 기기

### 보게 될 항목

| 항목 | 의미 |
|-------|---------|
| 기기 이름 | 예: 휴대폰 모델 또는 OS 이름. 식별할 수 없으면 "Unknown device"로 표시됨 |
| **Current device** (현재 기기) | 지금 사용 중인 기기 |
| **Last active** (마지막 활동) | 마지막으로 사용된 시각 |
| 활성 세션 | 이 기기에 있는 로그인 세션 수 |
| 출금 가능 시각 | 새 기기는 보통 출금하기 전에 일정 시간 기다려야 함 |

### 기기 제거

1. 알아볼 수 없는 기기 찾기 → **Remove** (제거) 탭
2. 확인하면 기기가 제거되며 **해당 기기의 로그인 세션이 즉시 무효화됩니다**

### 제거해야 할 때

- 휴대폰 / 컴퓨터를 바꿨는데 이전 기기가 아직 목록에 있을 때
- 로그인 기록에 알아볼 수 없는 기기가 있을 때
- 다른 사람이 내 계정을 사용하고 있다고 의심될 때

> 제거한 후 해당 기기는 다시 로그인해야 합니다 (이메일 인증 코드 / Telegram / Passkey).

***

## 2. Passkey

Passkey를 사용하면 코드를 입력하는 대신 휴대폰의 **Face ID, 지문 또는 화면 잠금**으로 로그인할 수 있습니다.

### Passkey 추가

1. 설정 → Passkeys → **Add passkey** (Passkey 추가)
2. 안내에 따라 Face ID / 지문 인증을 완료합니다
3. 완료되면 Passkey가 생성 시각, 마지막 사용 시각, 동기화 여부와 함께 목록에 표시됩니다

### 로그인에 사용하기

로그인 페이지에서 **Passkey**를 선택하세요 — 이메일이 필요 없습니다.

### Passkey 삭제

선택 → **Delete** (삭제) → 확인. 삭제한 후 해당 기기는 더 이상 Passkey로 로그인할 수 없습니다.

### 문제 해결

| 증상 | 해야 할 일 |
|---------|------------|
| 추가할 때 Face ID가 나타나지 않음 | 취소하고 **"Add Passkey"를 다시 탭한 후**, 안내가 나타나는 즉시 인증을 완료하세요. 먼저 알림 배너를 닫으세요 |
| 이 기기가 지원되지 않는다고 표시됨 | 시스템 기본 브라우저(iOS에서는 Safari, Android에서는 Chrome)를 사용하거나, 그냥 이메일 인증 코드를 사용하세요 |
| 같은 이름의 Passkey가 이미 있다고 표시됨 | 먼저 이전 "Android device" 항목을 삭제하세요. 프록시 / VPN을 사용 중이라면 끄고 다시 시도하세요 |
| 로그인 실패 | 대신 이메일 인증 코드로 로그인하세요. Passkey 실패는 계정 보안에 영향을 주지 않습니다 |

> Passkey는 로그인에만 사용할 수 있으며 **출금 인증에는 사용할 수 없습니다**.
