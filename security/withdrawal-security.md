# Withdrawal Security

提现会把资金转到外部地址，因此每次提现都需要 **step-up（二次验证）**。

![提现二次验证](../.gitbook/assets/withdraw_stepup_doc.png)

_建议截图：提现二次验证方式选择与 TOTP 输入_

***

## 验证优先级

1. **Authenticator 动态验证码**（已开启时优先，最推荐）
2. **Passkey**（未开 Authenticator 但已绑定 Passkey）
3. **邮箱验证码**（提现专用，不是登录码）

可在设置中查看「提现二次验证」说明。

***

## 提现时怎么做

1. 在提现页填好 Polygon 地址与金额并核对
2. 进入二次验证弹窗
3. 按提示完成 TOTP / Passkey / 邮箱码
4. 验证通过后再提交提现

验证码错误、过期、已使用或用途不匹配时，需要重新完成验证。

***

## 额外保护

| 机制 | 说明 |
|------|------|
| 最大可提 | 持仓与挂单占用不可提 |
| 新设备 / 安全冷却 | 新设备或风险变更后可能暂时无法提现 |
| 交易状态限制 | 账户若被限制交易，提现也可能受影响 |
| 地址核对 | 填错外部地址通常无法追回 |

***

## 安全提示

- 不要向自称客服的人提供提现验证码或 Passkey 确认
- 不要把提现地址改成「对方提供的中间地址」
- 官方邮件域名相关提示见 [Anti-Phishing](anti-phishing.md)
- 大额前提：小额试提 → 确认到账 → 再提大额
