# 钱包安全

CopyOdds 使用**托管交易账户**模型：你无需自行保管交易私钥，但需要保护好登录方式与提现验证。

完整说明页：App 内 **Asset security guarantee** → `/wallets/security`。

![资产安全保障](../.gitbook/assets/wallet_security_doc.png)

***

## 核心机制

| 能力 | 说明 |
|------|------|
| **独立钱包** | 每位用户独立托管钱包，资产隔离管理 |
| **私钥隔离** | 钱包私钥采用独立加密与隔离，不直接暴露给日常交易界面 |
| **提现保护** | 提现需二次验证；关键安全信息变更可能触发重新验证 / 冷却 |

***

## 平台安全保障（摘要）

若因 CopyOdds **平台自身**安全漏洞、服务器入侵等安全事件直接导致用户资产损失，平台将按安全保障政策承担相应赔付责任（以产品页与法律条款为准）。

但请注意：

- 平台**不会**通过私信、邮件或客服索要助记词、私钥、密码或验证码
- 预测市场交易亏损、用户自身操作错误（错链、错地址）、钓鱼诈骗等不在「平台安全事件赔付」的同一范畴
- 请始终通过官方域名操作

***

## 你需要自己做好的事

1. 只使用官方网站 / App：**copyodds.io**
2. **开启 Authenticator**（提现必须；见 [双重验证（2FA）](2fa.md)）
3. 可选添加 Passkey，方便登录
4. 管理登录设备，不信任陌生「客服」
5. 充值使用页面地址，并用「校验充值地址」核对
6. 首次充提先小额测试
