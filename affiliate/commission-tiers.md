# 分佣档位与升级

返佣比例不是固定的，它由你的**档位（L1–L7）**决定。档位越高，每笔下级套餐购买你拿到的比例越高。

入口：**Affiliation** → 右上角 **升级分佣档位（Upgrade commission tier）** → `/affiliate/upgrade`

***

## 档位与比例

| 档位 | 名称 | 分成比例 |
|------|------|----------|
| 未激活 | Basic | 0 |
| L1 | 社区成员 | 10% |
| L2 | 推荐伙伴 | 20% |
| L3 | 增长伙伴 | 30% |
| L4 | 渠道伙伴 | 40% |
| L5 | 市场伙伴 | 50% |
| L6 | 战略伙伴 | 60% |
| L7 | 生态伙伴（最高对外档位） | 70% |

> 更高的比例需要单独购买对应档位，页面上会列出**升级差价**：新档位标价 − 你已付档位抵扣。

***

## 怎么升级

### L1：完成一次购买即激活

买任意一个 **Gas 套餐**或**分佣档位**后，系统自动激活 L1（10%）。

### L2–L6：满足下级数量自动升级

| 目标档位 | 需要「直接下级」条件 |
|----------|----------------------|
| L2 | 3 个直接下级达到 L1 及以上 |
| L3 | 5 个直接下级达到 L1 及以上（其中至少 3 个达到 L2） |
| L4 | 8 个直接下级达到 L1 及以上（其中至少 3 个达到 L3） |
| L5 | 12 个直接下级达到 L1 及以上（其中至少 3 个达到 L4） |
| L6 | 20 个直接下级达到 L1 及以上（其中至少 3 个达到 L5） |

自动升级**不需要申请**，达标即生效。

### 最高档位：需要购买

L7 是对外可升级的最高档位，需要在**升级分佣档位**页面用 USDC 购买（升级时只补差价）。

***

## 升级页面能做什么

- 选择要购买的档位，查看**升级后**的分成比例
- **收益模拟器**：填「活跃下级人数」和「每位下级每月套餐消费」，估算每月佣金
- **解锁内容**：更高分成、用 USDC 余额支付、支付后立即生效、链上结算到你的充值地址
- 确认购买：核对**标价、已抵扣金额、实际支付金额**后再点确认

***

## 注意事项

- 佣金**只是收入提示，不保证实际到账金额**
- 档位只与**直接下级**有关，间接下级不计入
- 购买档位使用的是你**托管账户里的 USDC 余额**（与充值页余额是同一份）
- 活动与规则可能调整，以页面实时展示为准
