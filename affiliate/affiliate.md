# 邀请返佣（Affiliation）

把你的邀请链接分享给朋友，他注册并购买后，你就能拿到佣金。

入口：**Affiliation** → `/affiliate`

***

## 页面上的内容

| 区块 | 说明 |
|------|------|
| **邀请链接 / 邀请码** | 复制链接或邀请码发给朋友；通过你的链接注册会自动绑定关系 |
| **当前佣金比例** | 由你的档位决定，见 [分佣档位](commission-tiers.md) |
| **已邀请人数 / 预估收益** | 汇总数据 |
| **下级列表** | 可按用户 ID 或邀请码搜索，查看下级的档位与贡献 |
| **Telegram 机器人链接** | 若运营为你分配了专属机器人会显示；没有就用网页邀请链接 |
| **自动升级进度** | 告诉你离下一档还差多少直接下级 |

***

## 怎么拿到第一笔佣金

1. 完成任意一笔购买（Gas 套餐或分佣档位）→ **L1 自动激活**
2. 复制邀请链接发给朋友
3. 朋友通过链接注册
4. 朋友完成购买 → 你按当前档位比例获得佣金

> 佣金来自**下级的套餐购买**，不是来自下级的交易盈利；下级交易亏损不影响你的佣金。

***

## 升级档位

档位会根据你的下级数量**自动升级**，不需要手动申请。最高档位需要在 **Upgrade commission tier（升级分佣档位）** 页面购买开通。详见 [分佣档位与升级](commission-tiers.md)。

***

## 常见问题

**邀请码还没出现？**  
邀请码生成需要一点时间，刷新页面；仍未出现请联系客服。

**朋友注册后没有算我的下级？**  
确认对方是通过你的链接 / 邀请码注册的；已用其他方式注册的账号无法补绑。

**佣金多久结算？**  
以页面显示的记录为准，结算与档位规则相关。

**会不会影响我的账户安全？**  
邀请功能不需要你交出任何密码或验证码。**任何人索要验证码、验证码类「解冻」的都是骗子。**
