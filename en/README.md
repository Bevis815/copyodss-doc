# CopyOdds Docs

CopyOdds is a **smart money analytics + automated copy trading** platform built on [Polymarket](https://polymarket.com): discover prediction-market traders with strong track records, and automatically mirror their fills in a custodial trading account.

These docs reflect the current App (`app.copyodds.io`) interface and flows. Button and menu names match the App's English UI.

## Get started in four steps

1. **Log in / Sign up** — Email code, Passkey, or Telegram
2. **Deposit** — Send USDC / USDT on Polygon or BSC to your custodial address
3. **Buy Platform Gas** — Service-fee credits for automated copy trading (not on-chain MATIC)
4. **Copy** — Pick a trader in **Leaderboard** or **Smart money** → tap **Follow** → choose a copy mode (default: **Ratio**) → save the rule

Not sure where to begin? Start with the [App Tour](getting-started/app-tour.md).

## Before you start copying

| Item | Requirement |
|------|-------------|
| Platform Gas | **Greater than 0** (otherwise you can't enable copying; buys are skipped once Gas runs out) |
| USDC balance | At least about **$1** recommended, for the actual buys |
| Trading account | Usually opened automatically after login |
