# Using CopyOdds on Mobile (Mobile App)

You can use CopyOdds without downloading anything; choose whichever option suits you best.

Entry: **Mobile App** → `/mobile-app`

***

## Four ways to use it

| Option | Description | Best for |
|--------|-------------|----------|
| **Web** | Open directly in a browser, nothing to install | Desktop users, occasional use |
| **Add to Home Screen (PWA)** | Use the browser's "Add to Home Screen" for a full-screen experience and push notifications | Most mobile users (recommended) |
| **Telegram Mini App** | Open directly inside Telegram | People who live in Telegram |
| **Android App** | Download from Google Play | People who want a more native experience |

Supported devices: iPhone / iPad (Safari), Android (Chrome), Windows and Mac (Chrome / Edge).

***

## Recommended: Add to Home Screen (PWA)

CopyOdds is a PWA (Progressive Web App), so **you don't need an app store**. Once added to your home screen:

- **Full screen**, with no browser address bar
- **One-tap launch from the home screen icon**
- **Push notifications**, so you get copy alerts even when the App is closed

### How to install

- **iPhone / iPad**: Open the website in Safari → Share → **Add to Home Screen**
- **Android**: Open the website in Chrome → Menu → **Install app / Add to Home Screen**

If it says "Installed", you've added it before — just open it from the home screen icon.

***

## Android App

On the **Mobile App** or **Settings → Version** page you can see:

- The current App version
- Whether a new version is available (**Update Available** / **Up to date**)
- A link to Google Play, plus the release notes for that version

***

## How the interface differs on mobile

| Location | Content |
|----------|---------|
| Bottom tab bar | Leaderboard / Smart money / My copies / Deposit |
| Top-left menu | Everything else (Copy activity, Positions, Executions, Gas Store, Affiliation, Settings, etc.) |
| Pull to refresh | Most list pages refresh when you pull down |
| Opened inside Telegram | Automatically adapts to Telegram's back-button behavior |

## FAQ

**Do I have to download the App?**  
No. The web version is fully featured.

**Not getting push notifications after installing?**  
Make sure your phone's system settings allow notifications for the app; on iOS, enable notification permission for it in system Settings.

**Switched phones?**  
Log in again on the new device (email code / Telegram / Passkey), then remove the old device in [Device management](../account/devices-and-passkeys.md).
