# App Tour

The first time you open the App, it can be hard to know where to tap. This page explains every entry point in plain language so you can find your way.

> Tip: on mobile, the bottom bar has 4 common tabs (**Leaderboard / Smart money / My copies / Deposit**), and everything else is in the top-left menu; on desktop, it's all in the left sidebar.

***

## 1. Main features (top half of the left sidebar)

| Menu | What it is | When to use it |
|------|------------|----------------|
| **Leaderboard** | Copy pool ranking | See who in the platform's copy pool made the most today, and pick traders from there |
| **Smart money** | Trader screener | Filter traders by score, drawdown, and other criteria |
| **My copy trading** | Your copy rules | Manage the copy rules you've turned on (pause, resume, change settings) |
| **Simulation copy trading** | Practice mode | Try copy trading without real money first |
| **Store** | Gas Store | Buy Platform Gas (service-fee credits) |
| **My positions** | Your holdings | See which markets you hold, your cost, and whether you're up or down |
| **Executions** | Trade history | See the result of each copy attempt (filled / skipped / failed) |
| **Affiliation** | Affiliate program | Invite friends and earn commission |

***

## 2. Funds & settings (bottom half of the left sidebar)

| Menu | What it is | When to use it |
|------|------------|----------------|
| **Deposit** | Deposit | Move on-chain USDC / USDT into the platform |
| **Profile** | Your overview | See your Gas balance and wallet balance at a glance, with a shortcut to the affiliate page |
| **Withdraw** | Withdraw | Send USDC back to your own wallet address |
| **Settings** | Settings | Language, notifications, account linking, security status, App version |
| **Mobile App** | Mobile download | Add to your home screen / download the App |
| **User guide** | These docs | The documentation you're reading now |

***

## 3. Pages that are easy to mix up

| Page | In one sentence |
|------|-----------------|
| **Leaderboard** | Daily profit ranking of **copy pool accounts** |
| **Smart money** | Score, win rate, drawdown, and other profile data for **individual trader addresses** |
| **My positions** | What **you currently hold** |
| **Executions** | The result of **every order the system placed for you** |
| **Copy activity** | What the **trader** just did, and whether you copied it |
| **Transaction history** | **Money in and out** (deposits, withdrawals, Gas spending) |
| **Profile** | **Your asset overview** and the affiliate entry point |

***

## 4. Suggested order of use

1. **Log in**
2. **Deposit**
3. **Buy Gas**
4. **Pick a trader (Leaderboard / Smart money)**
5. **Tap Follow to copy** (default: **Ratio** mode)
6. Go back to **My copies** and confirm the status is **Following**

See [Quick Start](quick-start.md).
