# Supported Networks

充值与提现支持的网络**不对称**，请严格按页面选择，避免资产无法到账。

***

## 总览

| 操作 | 支持网络 | 资产 | 地址类型 |
|------|----------|------|----------|
| **充值** | **Polygon (PoS)**、**BSC**（功能启用时） | USDC / USDT | 各网络地址不同 |
| **提现** | **仅 Polygon (PoS)** | **USDC** | 你自己的收款地址 |

不支持作为充值网络的示例：**Ethereum 主网、Arbitrum、Optimism** 等（除非未来产品明确上线）。

***

## Polygon (PoS)

| 项 | 说明 |
|----|------|
| Chain ID | 137 |
| 充值 | 支持；展示的是托管钱包地址（Custodial address） |
| 资产 | USDC、USDT |
| 提现 | **唯一**提现网络；提 USDC 到可接收 Polygon USDC 的地址 |

大多数用户优先使用 Polygon：路径更直接，也与提现网络一致。

***

## BSC

| 项 | 说明 |
|----|------|
| Chain ID | 56 |
| 充值 | 支持（当桥接 / 产品网络启用时） |
| 资产 | USDC、USDT |
| 地址 | **Bridge address（桥接地址）**，与 Polygon 地址不同 |
| 提现 | **不支持**从 CopyOdds 提到 BSC |

从交易所提现到 BSC 时，请先在充值页切换到 BSC，再复制地址。到账可能多等几分钟。

***

## 易错对照

| 错误操作 | 后果 |
|----------|------|
| 在 BSC 提币，却复制了 Polygon 地址 | 可能无法入账 / 难找回 |
| 在 Polygon 提币，却复制了 BSC 地址 | 同上 |
| 提到 Ethereum USDC | 通常无法自动入账 |
| 把提现地址填成充值页地址 | 资金可能转回托管侧，造成混乱；提现应填**你自己的**外部地址 |
| 期望提到 BSC | 当前提现仅 Polygon USDC |

***

## 操作口诀

1. **充值前先选网络，再复制地址**
2. **Polygon 充、Polygon 提，最省事**
3. **BSC 只能充，不能从这个 App 提到 BSC**
4. **只用官方页面地址 + 校验充值地址功能**
