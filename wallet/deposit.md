# 充值

向 CopyOdds **交易账户**充入 USDC / USDT，用于跟单本金。入口：**Wallets → Deposit** → `/wallets/deposit`。

![充值页](../.gitbook/assets/usdc1_doc.png)

***

## 四步充值

1. **Pick network（选网络）** — Polygon (PoS) 或 BSC，与交易所提现网络一致  
2. **Pick asset（选资产）** — 仅 **USDC** 或 **USDT**  
3. **Send（转账）** — 复制或扫描**本页显示的地址**  
4. **Wait（等待）** — 链上确认后余额更新；BSC 可能多等几分钟

页面上还有 **充值步骤** 分区给出同样的四步说明，以及 **观看教程** 视频入口（`/guide-video`），第一次充值建议先看一遍。

### 三个省事小技巧

| 操作 | 说明 |
|------|------|
| **保存二维码** | 点「保存图片」把地址二维码存到手机，扫码比手输更不容易错 |
| **选网络后再复制** | 切到 BSC 后**必须重新复制**地址，两条链地址不同 |
| **只充本页当前展示的地址** | 不要用聊天记录或别人发来的旧地址 |

***

## 重要规则

| 规则 | 说明 |
|------|------|
| 支持的网络 | **Polygon (PoS)**（推荐）与 **BSC**；页面会标注「推荐 / 快速到账 / 低手续费」等标签 |
| 地址因网络而异 | Polygon 托管地址与 BSC 桥接地址**不同**，切勿混用 |
| 只收 USDC / USDT | 其他代币通常无法入账 |
| 不要用错链 | 不要使用 Ethereum / Arbitrum 等未支持网络 |
| 校验地址 | 可点 **校验充值地址**，系统会通过**官方 Telegram 机器人**或你的**绑定邮箱**把地址发给你核对 |
| 建议优先 USDC | Polygon 上的 USDT 常显示为「USDT (PoS)」；不要充 BNB 或其他币 |

### 校验充值地址怎么用

1. 点 **校验充值地址**
2. 页面提示你去启动官方 Telegram 机器人（`@机器人名`）或查看绑定邮箱
3. 收到地址后**逐位核对**与页面完全一致
4. 一致再确认操作

### 余额有两个数字

| 名词 | 意思 |
|------|------|
| **链上余额** | 区块链上实际到账的原生 USDC |
| **可交易余额** | 平台处理后能直接跟单的部分 |

刚到账若提示「链上有 xx 原生 USDC，正在自动兑换并转为可交易余额」，属于正常流程，稍等几分钟刷新即可。

## 操作细节

1. 登录并确认交易账户已可用
2. 进入充值页，先选网络再复制地址
3. 在交易所或钱包提现时：网络、币种与金额仔细核对
4. 回到 CopyOdds，必要时下拉刷新余额
5. 首次大额前建议：小额充值 → 确认到账 → 再大额

***

## 到账慢或没到账时

按顺序自查：

1. 提现网络是否与本页所选一致（Polygon vs BSC）
2. 币种是否为 USDC / USDT
3. 收款地址是否与本页**完全一致**
4. 链上交易是否已确认（可在对应区块浏览器查哈希）
5. 是否误提到了提现收款地址或其它平台地址

仍无到账：准备 **交易哈希、网络、金额、时间、注册邮箱** 联系支持。

***

## 充值后还要做什么？

- 若要开启跟单：先确认 **Polymarket 已就绪**，再 **购买平台 Gas**（见 [平台 Gas](gas.md)）
- 跟单买入需要可用 USDC（建议至少约 $1）

***

## 到账后去哪核对？

打开 **交易记录（Transaction history）** → `/wallets/ledger`，可以看到这笔充值的网络、资产、状态与操作后余额。详见 [资金流水](ledger.md)。
