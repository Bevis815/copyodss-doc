# 交易账户与钱包页状态说明

CopyOdds 的**交易账户在登录后通常自动开通**，你不需要额外申请。它是你的**托管交易钱包**：充值进来的 USDC / USDT 就在这里，用于跟单买卖。

入口：**交易账户（Wallets）** → `/wallets`（菜单里的 **Deposit** 就是这个页面）

***

## 正常情况下你会看到什么

| 区块 | 内容 |
|------|------|
| 链上充值地址 | 你的充值地址（**按网络不同**），可复制或保存二维码 |
| 可用余额 | 能直接用来跟单的部分 |
| 链上余额 | 区块链上实际到账的原生 USDC |
| 平台 Gas | 用来支付跟单服务费 |
| 提现 | 填 Polygon 收款地址与金额 |
| 交易记录 | 充值、提现、Gas 消费流水 |

看到这些就说明一切正常，可以直接充值。

***

## 两个余额为什么不一样

| 名词 | 意思 |
|------|------|
| **链上余额** | 区块链上实际到账的原生 USDC |
| **可交易余额** | 平台处理后能直接跟单的部分 |

刚到账时如果提示「链上有 xx 原生 USDC，正在自动兑换并转为可交易余额」，属于**正常流程**，稍等几分钟刷新即可。

***

## 偶尔会遇到的几种状态

这些提示不是每个人都会遇到；遇到了按下面的方式处理即可。

### 「尚未开通 CopyOdds 交易账户」

极少数情况下账户没有自动开通（比如开户时出过异常）。点 **开通交易账户**，阅读并勾选协议后确认即可。

协议大意：

| 条款 | 内容 |
|------|------|
| 服务内容 | 平台为你建立托管交易钱包，用于充值、跟单、下单、提现 |
| 托管与授权 | 资产由平台代管，你不直接持有私钥；你授权平台代为完成必要的签名与交易执行 |
| 提现保护 | 提现前可能要求先启用 **Authenticator（TOTP）** 二次验证 |
| 资金与网络 | 只向页面展示的地址与网络转入支持的资产；**选错网络或资产可能导致资金无法找回** |
| 风险提示 | 跟单**高风险，可能损失全部投入**；滑点、流动性、延迟都会影响结果 |
| 资格与合规 | 须年满 18 周岁；不得用于洗钱、欺诈等违法用途 |

> 协议内容会更新，完整条款以 App 内弹窗与《用户服务条款》为准。

### 出现「Agent 授权」区块

部分账户的钱包页会多出一个 **Agent 授权** 区块，作用是让你**签一次名就完成授权**，之后平台代你下单，**上链 Gas 由平台承担**（你不需要自备 MATIC）。

如果你看到了这个区块，按提示操作即可：

| 要求 | 说明 |
|------|------|
| 用**注册时那个钱包**签名 | 钱包里选错账户会提示「当前钱包不是注册钱包」 |
| 钱包切到 **Polygon（链 ID 137）** | 否则提示「请将钱包切到 Polygon 后重试」 |
| 一次完成签名 | 中途关插件或改内容会失败，刷新重来 |
| 注意有效期 | 到期后跟单暂停，点 **续期** 即可；也可主动 **撤销**（撤销后需重新授权） |

常见报错：钱包不对 / 链不对 / 授权请求已过期 / 签名内容与校验不一致（多为插件干扰，刷新重试）。

### 「Polymarket 交易授权未完成」

点 **重新授权 Polymarket**。这类提示属于授权环节的异常，**不影响你已经充值的资金**。

> 极少数自动授权失败时，页面提供「手动粘贴 Polymarket API 凭据（高阶）」入口，用于排查，普通用户不需要碰。

## 常见问题

**交易账户要收费吗？**  
开通本身不收费。只有跟单成交时才按约 0.5% 扣平台 Gas。

**我的私钥在哪里？**  
不在你手上。CopyOdds 使用托管钱包，私钥由平台隔离保管，你通过登录 + 提现二次验证控制资金。

**为什么能看到链上地址却不能自己转走？**  
这是托管设计：地址归属平台，用于接收你的充值。要把资金转出必须走**提现**流程并完成二次验证。

**这两个余额什么时候会不一样？**  
通常只在**刚到账、正在自动兑换**的那几分钟。长时间不一致请刷新，仍异常请联系支持并提供交易哈希。
