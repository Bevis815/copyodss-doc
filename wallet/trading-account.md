# 开通交易账户与授权（充值前必看）

在充值之前，你的账户要先**开通 CopyOdds 交易账户**并**完成授权**，之后才能正常跟单。这一页把这条链路讲清楚。

入口：**交易账户（Wallets）** → `/wallets`（菜单里的 **Deposit** 就是这个页面）

***

## 整体流程

```text
登录
  ↓
开通 CopyOdds 交易账户（阅读并同意协议）
  ↓
授权 Agent（钱包签一次名）
  ↓
确认「Polymarket 已就绪」
  ↓
向页面显示的地址充值 USDC / USDT
  ↓
买 Gas → 开始跟单
```

> 新手引导页会直接提示「**先授权 Agent，再充值 USDC**」。

***

## 第 1 步：开通交易账户

1. 登录后进入钱包页
2. 若显示「**尚未开通 CopyOdds 交易账户**」，点 **开通交易账户**
3. 弹出的协议需要**勾选「我已阅读并同意以上协议」**后才能确认
4. 确认后系统会生成属于你的链上地址

### 协议讲了什么（摘要）

| 条款 | 内容 |
|------|------|
| 服务内容 | 平台为你建立**托管交易钱包**（含链上执行地址与 Polymarket 充值 / 交易地址），用于充值、跟单、下单、提现 |
| 托管与授权 | 资产由平台系统代管，**你不直接持有私钥**；你授权平台在必要范围内代为完成 Polymarket 的授权、签名与交易执行 |
| 提现保护 | 平台可能要求先启用 **Authenticator（TOTP）** 等二次验证才能提现 |
| 资金与网络 | 只向页面展示的地址与网络转入 **Polygon (PoS) 上的 USDC / USDT**；**选错网络或资产可能导致资金无法找回** |
| 风险提示 | 预测市场与跟单**高风险，可能损失全部投入**；过往业绩不代表未来；滑点、流动性、延迟都会影响结果 |
| 资格与合规 | 须年满 18 周岁（或当地法定成年年龄）；不得用于洗钱、欺诈等违法用途 |
| 费用 | 平台可能收取跟单手续费、Gas 套餐等，以页面公示为准 |

> 协议还会不定时更新，继续使用即视为接受；完整内容以 App 内弹窗为准。

***

## 第 2 步：授权 Agent

**Agent 授权**是新版跟单能"自动执行"的关键：你用钱包**签一次名**，之后平台代你完成下单，**上链手续费由平台承担**（你不需要自己准备 MATIC）。

### 怎么授权

1. 在钱包页找到 **Agent 授权** 区块
2. 点 **立即授权** / **用钱包授权**
3. 按提示完成签名，页面会依次显示：准备签名资料 → 请在钱包中确认签名 → 提交授权 → 等待链上生效
4. 成功后显示 **Agent 已授权** 与**有效至某天**

### 授权时的关键要求

| 要求 | 说明 |
|------|------|
| **用注册时的那个钱包签名** | 签错账户会提示「当前钱包不是注册钱包」，按提示切换即可 |
| **钱包切到 Polygon（链 ID 137）** | 否则会提示「请将钱包切到 Polygon 后重试」 |
| **签名要一次完成** | 中途关掉插件或改内容会失败，刷新页面重来 |
| **授权有有效期** | 到期后跟单会暂停，点 **续期** 即可 |

### 常见报错

| 提示 | 原因 | 怎么办 |
|------|------|------|
| 当前钱包不是注册钱包 | 钱包里有多个账户 | 点「切换到 xxx」后再授权 |
| 请切到 Polygon（137） | 链不对 | 在钱包里切换网络 |
| 授权请求已过期 | 放太久了 | 重新点一次授权 |
| 签名内容与校验不一致 | 插件干扰 / 内容被改 | 刷新重试，暂时关掉其他钱包插件 |
| 平台 Agent 尚未就绪 | 服务端问题 | 等一会儿重试 |

### 撤销授权

点 **撤销** 即可。**撤销后跟单会暂停**，需要重新授权才能继续。

***

## 第 3 步：确认 Polymarket 已就绪

钱包页会显示授权状态：

| 状态 | 含义 | 你要做什么 |
|------|------|------------|
| **Polymarket 已就绪** | 一切正常 | 可以充值了 |
| **Polymarket 交易授权未完成** | 账户开了但授权没完成 | 点 **重新授权 Polymarket**，否则**无法跟单下单** |

> 极少数情况自动授权失败时，页面提供「手动粘贴 Polymarket API 凭据（高阶）」入口，需要你自己在 Polymarket 上为当前托管地址派生的 key。这属于排查用的高级功能，普通用户不需要碰。

***

## 第 4 步：充值

授权完成后，回到充值页按 [充值](deposit.md) 的四步操作即可。

余额有两个数字，不用慌：

| 名词 | 意思 |
|------|------|
| **链上余额** | 区块链上实际到账的原生 USDC |
| **可交易余额** | 平台处理后、能直接用来跟单的部分 |

刚到账时如果提示「链上有 xx 原生 USDC，正在自动兑换并转为可交易余额」，稍等几分钟刷新即可。

***

## 常见问题

**授权 Agent 要花钱吗？**  
不用，签名本身不收费，上链 Gas 由平台承担。你只需要有那个注册钱包即可。

**授权会暴露我的私钥吗？**  
不会。你只是**签一次名授权**，私钥始终在你的钱包里，CopyOdds 使用的是平台代管的托管地址。

**为什么必须用注册时的钱包？**  
授权要和你账户的链上地址对应，换钱包签名系统无法确认是你本人。

**授权过期会影响已有跟单吗？**  
会暂停后续下单。重新授权（续期）后恢复；已有持仓不受影响。

**暂时不打算跟单，可以不授权吗？**  
可以先不授权，但**不完成授权就无法跟单下单**。建议在充值前先完成，避免钱到了却无法使用。
