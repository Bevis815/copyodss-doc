# 资金流水（Transaction history）

**资金流水**记录你账户里每一笔资金的进出与 Gas 消费，相当于一张对账单。

入口：**交易记录（Transaction history）** → `/wallets/ledger`（一般在充值 / 提现页面里能跳转过来）

***

## 表格里的字段

| 字段 | 含义 |
|------|------|
| **网络 / 资产** | 例如 Polygon (PoS) + USDC、BSC + USDT、Platform + Gas |
| **类型（In / Out）** | 入账还是出账 |
| **状态** | 已入账（Received）、已完成（Completed）、已入账（Posted） |
| **操作后余额** | 这笔之后账户还剩多少 |
| **查看链上** | 跳到区块链浏览器查看这笔交易 |

三类记录：

| 类型 | 说明 |
|------|------|
| **充值** | 从外部钱包转入 USDC / USDT |
| **提现** | 提到你自己的地址 |
| **Gas 消费** | 每笔跟单成交扣掉的服务费点数 |

***

## 对不上账的时候

| 现象 | 排查方向 |
|------|----------|
| 充值没出现 | 网络是否选对、资产是否 USDC/USDT、地址是否与该网络页面完全一致、链上是否已确认（BSC 更慢） |
| 提现一直「处理中」 | 需先完成提现二次验证；新设备或风险变更后可能有冷却时间 |
| Gas 扣得比预期多 | 每笔买入和卖出都按成交额约 0.5% 扣；可对照 [平台 Gas](gas.md) 的举例换算 |
| 余额和持仓对不上 | 持仓与挂单会占用资金，以「最大可提」为准 |

查不到时，请把流水里的**时间、金额、状态**连同链上哈希发给客服。
