# Leaderboard (profit quotidien du pool de copie)

Le **Leaderboard** (classement) est la page d'accueil de l'App (`/`). Il classe les comptes du pool de copie de la plateforme selon leur **profit quotidien** — en somme, un « bulletin de notes de ceux qui ont bien copié récemment ».

La page affiche la **date du classement (jour ouvré)** ; l'heure de début du jour ouvré est celle indiquée sur la page.

***

## Contenu de la page

| Élément | Signification |
|---------|---------|
| **Board · date** | Le jour couvert par ce classement |
| **Daily PnL** | Ce que le compte a gagné sur ce jour ouvré |
| **7D** | P&L sur les 7 derniers jours |
| **Current leader / Rank** | Position dans le classement |
| **View analysis / View account** | Accéder aux détails du compte |
| **Top N / All N** | Afficher uniquement les premiers, ou déplier le classement complet |

***

## Comment l'utiliser

1. Ouvrez l'App — vous arrivez par défaut sur le Leaderboard
2. Regardez d'abord **Daily PnL + 7D** ; une journée profitable ne signifie pas de la régularité
3. Appuyez sur **View analysis** ou **View account** pour voir qui ce compte copie
4. Une fois convaincu, appuyez sur **Follow** (suivre) directement dans le classement pour ouvrir la fenêtre des paramètres de copie

> Les comptes du classement sont eux-mêmes des copieurs — leurs profits montrent que « copier ce type de trader fonctionne parfois », et non que vous gagnerez autant si vous copiez.

***

## Points à garder en tête

- Le classement est mis à jour chaque jour ; le rang d'hier n'est pas reporté sur aujourd'hui
- Le profit quotidien est facilement porté par un seul gros pari, alors **ne regardez pas seulement le n° 1**
- Pour choisir des traders selon des critères plus fins, utilisez les filtres de [Smart money](leaderboard.md)
- Les adresses du classement peuvent être partagées directement : `https://app.copyodds.io/@0xADDRESS`
