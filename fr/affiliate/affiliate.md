# Programme d'affiliation (Affiliation)

Partagez votre lien d'invitation avec vos amis — dès qu'ils s'inscrivent et effectuent un achat, vous gagnez une commission.

Accès : **Affiliation** → `/affiliate`

***

## Contenu de la page

| Section | Description |
|---------|-------------|
| **Invite link / Invite code** | Copiez le lien ou le code et envoyez-le à vos amis ; s'inscrire via votre lien les associe automatiquement à vous |
| **Current commission rate** | Déterminé par votre niveau ; voir [Niveaux de commission](commission-tiers.md) |
| **Invited users / Estimated earnings** | Données récapitulatives |
| **Referral list** | Recherchez par ID utilisateur ou code d'invitation pour voir les niveaux et contributions de vos filleuls |
| **Telegram bot link** | Affiché si l'équipe vous a attribué un bot dédié ; sinon, utilisez le lien d'invitation web |
| **Auto-upgrade progress** | Combien de filleuls directs supplémentaires il vous faut pour le niveau suivant |

***

## Comment gagner votre première commission

1. Effectuez n'importe quel achat (un forfait de Gas ou un niveau de commission) → **le niveau L1 est activé automatiquement**
2. Copiez votre lien d'invitation et envoyez-le à vos amis
3. Votre ami s'inscrit via le lien
4. Votre ami effectue un achat → vous gagnez une commission au taux de votre niveau actuel

> La commission provient des **achats de forfaits de vos filleuls**, et non de leurs profits de trading ; les pertes de trading de vos filleuls n'affectent pas votre commission.

***

## Monter de niveau

Votre niveau **augmente automatiquement** en fonction de votre nombre de filleuls — aucune demande n'est nécessaire. Le niveau le plus élevé doit être acheté sur la page **Upgrade commission tier** (passer au niveau de commission supérieur). Voir [Niveaux de commission et passages de niveau](commission-tiers.md).

***

## FAQ

**Mon code d'invitation n'apparaît pas encore ?**  
La génération du code d'invitation prend un moment — actualisez la page ; s'il n'apparaît toujours pas, contactez le support.

**Mon ami s'est inscrit mais n'est pas comptabilisé comme mon filleul ?**  
Assurez-vous qu'il s'est inscrit via votre lien / code d'invitation ; les comptes déjà enregistrés par un autre moyen ne peuvent pas être associés rétroactivement.

**Quand la commission est-elle réglée ?**  
Fiez-vous aux enregistrements affichés sur la page ; le règlement dépend des règles de votre niveau.

**Cela affectera-t-il la sécurité de mon compte ?**  
La fonctionnalité d'affiliation ne vous demande jamais de communiquer un mot de passe ou un code de vérification. **Toute personne qui vous demande votre code de vérification, ou qui propose un « déblocage » contre un code, est un escroc.**
