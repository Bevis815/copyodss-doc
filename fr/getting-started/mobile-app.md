# Utiliser CopyOdds sur mobile (Mobile App)

Vous pouvez utiliser CopyOdds sans rien télécharger ; choisissez l'option qui vous convient le mieux.

Accès : **Mobile App** → `/mobile-app`

***

## Quatre façons de l'utiliser

| Option | Description | Idéal pour |
|--------|-------------|----------|
| **Web** | Ouvrez directement dans un navigateur, rien à installer | Utilisateurs sur ordinateur, usage occasionnel |
| **Ajouter à l'écran d'accueil (PWA)** | Utilisez la fonction « Ajouter à l'écran d'accueil » du navigateur pour une expérience plein écran et des notifications push | La plupart des utilisateurs mobiles (recommandé) |
| **Mini App Telegram** | Ouvrez directement dans Telegram | Les personnes qui vivent sur Telegram |
| **App Android** | Téléchargez-la depuis Google Play | Les personnes qui veulent une expérience plus native |

Appareils pris en charge : iPhone / iPad (Safari), Android (Chrome), Windows et Mac (Chrome / Edge).

***

## Recommandé : Ajouter à l'écran d'accueil (PWA)

CopyOdds est une PWA (Progressive Web App), **vous n'avez donc pas besoin d'une boutique d'applications**. Une fois ajoutée à votre écran d'accueil :

- **Plein écran**, sans barre d'adresse du navigateur
- **Lancement en un geste depuis l'icône de l'écran d'accueil**
- **Notifications push**, pour recevoir les alertes de copie même lorsque l'App est fermée

### Comment l'installer

- **iPhone / iPad** : ouvrez le site dans Safari → Partager → **Sur l'écran d'accueil**
- **Android** : ouvrez le site dans Chrome → Menu → **Installer l'application / Ajouter à l'écran d'accueil**

S'il est indiqué « Installed » (installée), vous l'avez déjà ajoutée — ouvrez-la simplement depuis l'icône de l'écran d'accueil.

## App Android

Sur la page **Mobile App** ou **Settings → Version**, vous pouvez voir :

- La version actuelle de l'App
- Si une nouvelle version est disponible (**Update Available** / **Up to date**)
- Un lien vers Google Play, ainsi que les notes de version correspondantes

***

## Différences de l'interface sur mobile

| Emplacement | Contenu |
|----------|---------|
| Barre d'onglets inférieure | Leaderboard / Smart money / My copies / Deposit |
| Menu en haut à gauche | Tout le reste (Copy activity, Positions, Executions, Gas Store, Affiliation, Settings, etc.) |
| Tirer pour actualiser | La plupart des pages de liste s'actualisent lorsque vous tirez vers le bas |
| Ouverture dans Telegram | S'adapte automatiquement au comportement du bouton retour de Telegram |

## FAQ

**Dois-je télécharger l'App ?**  
Non. La version web est complète.

**Vous ne recevez pas de notifications push après l'installation ?**  
Assurez-vous que les paramètres système de votre téléphone autorisent les notifications pour l'application ; sur iOS, activez l'autorisation de notification pour celle-ci dans les Réglages du système.

**Vous avez changé de téléphone ?**  
Reconnectez-vous sur le nouvel appareil (code par e-mail / Telegram / Passkey), puis supprimez l'ancien appareil dans la [Gestion des appareils](../account/devices-and-passkeys.md).
