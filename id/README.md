# Dokumentasi CopyOdds

CopyOdds adalah platform **analitik smart money + copy trading otomatis** yang dibangun di atas [Polymarket](https://polymarket.com): temukan trader pasar prediksi dengan rekam jejak yang kuat, dan tiru transaksi mereka secara otomatis di akun trading kustodian.

Dokumentasi ini mencerminkan antarmuka dan alur App (`app.copyodds.io`) saat ini. Nama tombol dan menu sesuai dengan UI App berbahasa Inggris.

## Mulai dalam empat langkah

1. **Masuk / Daftar** — Kode email, Passkey, atau Telegram
2. **Deposit** — Kirim USDC / USDT di Polygon atau BSC ke alamat kustodian Anda
3. **Beli Gas Platform** — Kredit biaya layanan untuk copy trading otomatis (bukan MATIC on-chain)
4. **Copy** — Pilih trader di **Leaderboard** atau **Smart money** → ketuk **Follow** (ikuti) → pilih mode copy (default: **Ratio**) → simpan aturan

Tidak yakin harus mulai dari mana? Mulailah dengan [Tur Aplikasi](getting-started/app-tour.md).

## Sebelum Anda mulai meng-copy

| Item | Persyaratan |
|------|-------------|
| Gas Platform | **Lebih dari 0** (jika tidak, Anda tidak dapat mengaktifkan copy; pembelian dilewati begitu Gas habis) |
| Saldo USDC | Disarankan minimal sekitar **$1**, untuk pembelian sebenarnya |
| Akun trading | Biasanya dibuka secara otomatis setelah masuk |
