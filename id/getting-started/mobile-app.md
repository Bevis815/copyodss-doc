# Menggunakan CopyOdds di Ponsel (Mobile App)

Anda dapat menggunakan CopyOdds tanpa mengunduh apa pun; pilih opsi yang paling sesuai untuk Anda.

Titik masuk: **Mobile App** → `/mobile-app`

***

## Empat cara menggunakannya

| Opsi | Deskripsi | Paling cocok untuk |
|--------|-------------|----------|
| **Web** | Buka langsung di browser, tidak perlu menginstal apa pun | Pengguna desktop, penggunaan sesekali |
| **Tambahkan ke Layar Utama (PWA)** | Gunakan "Tambahkan ke Layar Utama" di browser untuk pengalaman layar penuh dan notifikasi push | Sebagian besar pengguna ponsel (disarankan) |
| **Telegram Mini App** | Buka langsung di dalam Telegram | Orang yang sehari-hari menggunakan Telegram |
| **Aplikasi Android** | Unduh dari Google Play | Orang yang menginginkan pengalaman yang lebih native |

Perangkat yang didukung: iPhone / iPad (Safari), Android (Chrome), Windows dan Mac (Chrome / Edge).

***

## Disarankan: Tambahkan ke Layar Utama (PWA)

CopyOdds adalah PWA (Progressive Web App), jadi **Anda tidak memerlukan app store**. Setelah ditambahkan ke layar utama:

- **Layar penuh**, tanpa bilah alamat browser
- **Diluncurkan dengan sekali ketuk dari ikon layar utama**
- **Notifikasi push**, sehingga Anda tetap menerima peringatan copy meskipun App ditutup

### Cara menginstal

- **iPhone / iPad**: Buka situs web di Safari → Bagikan → **Add to Home Screen** (Tambahkan ke Layar Utama)
- **Android**: Buka situs web di Chrome → Menu → **Install app / Add to Home Screen** (Instal aplikasi / Tambahkan ke Layar Utama)

Jika muncul "Installed", berarti Anda sudah pernah menambahkannya — cukup buka dari ikon layar utama.

## Aplikasi Android

Di halaman **Mobile App** atau **Settings → Version** Anda dapat melihat:

- Versi App saat ini
- Apakah versi baru tersedia (**Update Available** / **Up to date**)
- Tautan ke Google Play, beserta catatan rilis untuk versi tersebut

## FAQ

**Apakah saya harus mengunduh App?**  
Tidak. Versi web memiliki fitur lengkap.

**Tidak menerima notifikasi push setelah menginstal?**  
Pastikan pengaturan sistem ponsel Anda mengizinkan notifikasi untuk aplikasi tersebut; di iOS, aktifkan izin notifikasi untuknya di Pengaturan sistem.

**Berganti ponsel?**  
Masuk kembali di perangkat baru (kode email / Telegram / Passkey), lalu hapus perangkat lama di [Manajemen perangkat](../account/devices-and-passkeys.md).
